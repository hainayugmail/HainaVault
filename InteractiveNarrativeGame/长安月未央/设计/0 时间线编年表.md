**《长安月未央》创作参考文档**

# 一、时间线编年表

_说明：年号__“景宁”为建议拟定，仅供统一时间线校对使用，如已有其他构想请直接替换。_

| **时间节点（拟年号：景宁）** | **阶段**  | **关键事件**                                 |
| ---------------- | ------- | ---------------------------------------- |
| 景宁元年             | 入宫前后    | 春宴"龙凤胎"解围→封女史→入宫当差                       |
| 景宁元年末—二年         | 初期蛰伏    | 太后与贺娘娘旧案打听；宫殿命名与分配；升掌记                   |
| 景宁二年春            | 华阳之乱    | 《厘正选官疏》→羽林军哗变→韩崇被俘→太后三道懿旨收买人心            |
| 景宁二年             | 舆论反击    | 长安雇闲汉散布流言，为陛下正名                          |
| 景宁二年秋—三年         | 大婚与后宫初定 | 皇后大婚、四妃入宫、六位宝林入采芳苑                       |
| 景宁三年             | 宫斗磨合期   | 千秋宴鹿筋事件、戒尺事件、段淑妃/慕容昭仪结交、何婕妤卧底行刺（陛下重伤，隐瞒） |
| 景宁三年末            | 宫宴刺杀    | 段淑妃、慕容昭仪负伤挡刺客；何婕妤服毒身亡真相揭晓                |
| 景宁四年             | 裴尚书死谏   | 裴尚书撞柱自刺而亡→段淑妃降为嫔→裴家借势安插官员                |
| 景宁四年             | 太后试探    | 太后借王贵人前身试探长安与御书房关系，长安以“裴家渊源”化解           |
| 景宁四年秋            | 六镇账目案   | 长安查出伪造签收单→裴颜卿彻查穆常侍克扣军饷                   |
| 景宁四年冬            | 穆常侍伏诛   | 当殿斩首，穆党连坐清洗，太后三次逼宫失败改称病                  |
| 景宁五年初            | 亲征      | 群臣劝阻→雁鸣坡设伏（鲁承恩告密）→韩崇驰援→大捷→柔然来犯→蠕蠕王俘获→归京  |
| 景宁五年             | 归京清算    | 太后被摊牌账目震慑；裴家封赏被刻意压制；皇后再孕                 |
| 景宁五年末            | 选秀      | 罗昭仪、周美人等新人入宫；德妃让权博弈（王贵人线）                |
| 景宁六年             | 公主降生    | 皇后产女→公主先由德妃抚养后归还皇后；周美人一尸两命               |
| 景宁六年末—七年         | 收尾      | 太后彻底失势→薨逝→皇后主动请辞出家，法号净安                  |
