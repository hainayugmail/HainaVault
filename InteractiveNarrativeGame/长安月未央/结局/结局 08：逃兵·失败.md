### 结局 08：逃兵·失败

**触发路径**：女主想走，但皇帝好感度太高，他不放她走。

| 阶段    | 关键选择                | 可选/必须 |     |
| ----- | ------------------- | ----- | --- |
| 初期-后期 | 同结局G的所有"想走"选择       | —     |     |
| 终局    | 太后倒台后 → 选择"向皇帝提出辞官" | 必须    |     |
| 终局    | 皇帝拒绝 → 选择"坚持要走"     | 必须    |     |

| 数值要求  | 阈值         |
| ----- | ---------- |
| 皇帝好感度 | ≥85（他不放你走） |
| 自由值   | ≥80        |

**结局内容**：皇帝不放她走，她留在了宫里。她赢了所有的棋局，却输掉了最初想要的那条路。她偶尔会在半夜醒来望着月亮，想起很多年前数着出宫日子的自己。
