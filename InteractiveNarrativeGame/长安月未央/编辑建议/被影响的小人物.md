# 新增人物触发系统设计

## 一、邻居女孩线（暂命名：阿蕖）

**登场时机**：建议插入在女主还是女史/掌记初期、休沐回家的章节（对应正文2-7章之间的某次探亲），作为一个一次性播种、后续分阶段收割的支线。

|阶段|触发点|选择|数值影响|
|---|---|---|---|
|埋线（一次性）|某次休沐回家，邻居女孩趴墙头看女主写字|**教她认几个字** / **敷衍带过不教**|前者：阿蕖线激活=1；后者：阿蕖线激活=0|
|中期强化（可选，2-3次）|之后每次回家，是否抽空多教她一些|**继续教** / **没空/忘了**|每次"继续教"+1蒙学值，累计到阈值解锁"高阶女官"分支|
|后期收束|阿蕖及笄前后|根据蒙学值判定|蒙学值≥3 → 女官线；蒙学值1-2 → 半吊子读写，嫁人线附带"孩子也想学"的伏笔更强；蒙学值=0 → 纯嫁人线，孩子求学作为纯粹的意外邂逅|

**分支结局**：

- **A. 女官线**（蒙学值≥3）：阿蕖后来自己考入内务府，凭着底子一路做到女官高位，多年后与已经身居高位的女主在某处宫务上重逢，成为女主在后宫体系里少数"自己人"，可以作为女主任何结局线里的一个稳定辅助角色（比如结局12"女后德妃掌宫"里，阿蕖可以是女主用来平衡德妃的另一支力量）。
- **B. 嫁人+孩子求学线**（蒙学值0-2）：阿蕖嫁到邻村/邻坊，多年后她的女儿趴在女主门口，像当年阿蕖一样，怯生生地问"姐姐能不能教我写字"。这里可以做成一个明确的镜像场景，直接复刻第一次教字的画面细节（比如同一个姿势、同一句话），只是这次女主的身份、心境、能不能抽出空，都已经完全不同了——是很好的时间厚度的体现。

**与皇帝/女主关系**：不涉及皇帝，是纯粹的女主个人支线，功能是给玩家一个"选择的重量会隔代显现"的体验，也给女主的人物弧光加一层"她如何对待自己手里那点微小的权力"的侧写。

## 二、逃难小孩线（暂命名：阿武，去边镇路上所遇）

**登场时机**：建议插入在第26章"亲征"或28章"外敌"前后，女主随军或整理边关事务途中路遇的孩童，是一个纯粹发生在边关线上的支线，三选一分支，互斥。

|触发点|选择|后续|
|---|---|---|
|路遇逃难投亲的孩子，衣衫褴褛、独自赶路|**A. 出手相帮**（给吃食/引荐给军中/记下他的名字）|帮扶值+1，激活"护国将军"线|
||**B. 无视/自顾不暇未管**|什么都不触发，孩子自然流落，激活"柔然王"线|
||**C. 起了疑心，认为是奸细/骗子，任由他被驱赶或被人伤害**|激活"阉人"线（这条需要明确是女主主动的猜疑导致的伤害，而非单纯路过没管）|

三条线互斥，一次通关只能触发其中一支，建议做成一个"当下必须立刻决定"的强制选择点，不给玩家犹豫/回头的空间，这样才能撑起"一念之差决定一个人一生"的分量。

**分支结局细化**：

- **A. 护国将军线**：孩子被引荐入伍或被军中收留，多年后成长为独当一面的边关将领，很适合安排他在雁鸣坡之后的某场边关战事里（比如结局线里柔然反扑、或者"权力轮回"结局的太后倒台后动荡期）以救场者身份登场，与韩崇/新一代边军形成传承关系。可以让他在某个瞬间认出女主，说一句类似"当年是您给了我一口吃的"，形成因果闭环。
    
- **B. 柔然王线**：孩子流落草原，被柔然部族收留养大，多年后成为柔然新一代首领。这条线最适合安放在游戏的**后期黑暗结局**（比如"皇帝黑化""权力轮回"）里，作为边境新一轮战争的对手方登场——如果玩家选了不管，等于亲手埋下了未来边患的种子，这是一个很漂亮的"善小而不为"的因果设计，也能让"柔然"这个原本只是外敌背景板的势力多一层具体的人物质感。
    
- **C. 阉人线（信物暗线）**：孩子被伤害后净身入宫，成为皇帝身边一个毫不起眼、只负责倒水侍立的小太监。这条线的关键是**信物**——建议设计成孩子随身带着一件东西（比如一枚磨得发亮的铜钱、一个歪歪扭扭缝的荷包），净身入宫后这件东西被他悄悄留在身边。多年后女主如果在某个场景里无意瞥见这个太监手上/身上的信物，才惊觉当年那个孩子就在自己眼皮底下，且这些年一直安静地侍立在皇帝身边，从未被认出——这是一个非常适合埋在游戏"隐藏细节/彩蛋"里的线索，不需要靠对话点破，靠玩家自己观察发现，效果会比直接揭示更有冲击力。
    

**与皇帝/女主关系**：A、B两条线的孩子长大后都与皇帝的国家机器直接产生对抗或效力关系（一为己用、一为敌手），C线的孩子则贴身服侍皇帝本人，是三条线里唯一一个"离权力中心最近，却最没有存在感"的结局，也最适合承载"女主的一次疑心，可能毁掉一个人的一生"这个警示性主题。

三个人物（阿蕖不算在内，逃难小孩A/B/C视为一个人物三条互斥支线）加起来，触发点集中、互斥清晰，不会互相打架。你看这套设计方向是否合适，没问题的话我下一轮就把邻居女孩初遇+逃难小孩三岔口那两段完整场景写出来。

**选项本身要写得"轻"，不要暗示后果**  
比如遇到逃难小孩那个选择点，UI上不能写"帮助这个孩子（将影响他未来的命运）"，而应该就写"给他半块干粮" / "无暇他顾，继续赶路" / "让人把这个来路不明的孩子赶走"——纯粹是当下情境的自然反应，不带任何提示性文字。玩家做选择的时候，应该完全意识不到这是个"命运级"节点，这样后面揭晓时才有冲击力。

**2. 不要在游戏内直接告诉玩家"你影响了谁"**  
最好是让玩家自己拼图。比如多年后边关那位将领只是随口提了一句"当年在逃难路上,有个姑娘给过我半块饼"，不点明是谁；或者阉人线里，那个信物只在某个场景的环境描写里一闪而过，不加解释。真正玩得细的玩家会自己反应过来，这种"自己发现"的满足感比游戏明说效果强得多。

**3. 可以设计一个"多周目"或"回顾"机制强化这种感觉**  
比如通关后有个"人物志"或"命运回廊"页面，只有在特定分支下才会解锁某个人物的完整轨迹图——玩家第一周目可能完全没意识到自己做了什么，第二周目选了不同选项，才发现同一个NPC走向了截然不同的路，这时候"原来是我"的感觉会被放大。

这套"随手之举，命运轰鸣"的设计思路，其实跟你正文里"太后当年一句童谣就灭了贺家满门"这种"看似轻巧的一句话，酿成灭门大祸"的母题是同构的——都是在说这深宫内外，权力和善意一样，都可能轻飘飘地压垮一个具体的人。这样一来这几个小人物支线就不只是"加内容"，而是和主线的核心命题呼应上了。
