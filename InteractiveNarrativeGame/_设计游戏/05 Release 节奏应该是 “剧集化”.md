如何设计，才便于逐步发布、积累人气

release 节奏应该是 “剧集化”，不是传统大版本思维。

最适合的路线是 5 个阶段

Stage 0：世界观预热

- 发角色图
- 发异常片段
- 发“梦境日志”
- 发短视频剪辑
- 不急着放太多系统

目的不是卖玩法，是卖气质。

Stage 1：Demo《松鼠大战》

只做：

- 林晓单角色
- 新手操作
- 松鼠 Boss
- 2～3 个死亡结局
- 1 个惨胜结局
- 1 个绝杀结局
- 现实回响结尾

这个阶段的目标不是时长，而是传播性。

Stage 2：第一章网络互动版

增加：

- 登录
- 章节进度
- 观战/讨论
- 简单多人围观互动
- Bot 占位
- 轻量排行榜

先做“有联网感”，不是“真 MMO”。

Stage 3：双主角协作

增加：

- Luca 可选
- 双角色配合
- 读心 UI
- 小队协作
- 单人带 Bot / 双人联机

Stage 4：副本化

增加：

- 松鼠副本
- 乌鸦副本
- 角色练习模式
- 每周变体 Boss

Stage 5：虚拟空间化

增加：

- 人界安全区
- 小队集结
- 场景内角色互动
- 长期运营活动
