文档怎么建，才不会写着写着崩掉

四类小文档。

A. 角色文档

每个角色一页，固定格式：

- 姓名 / 阵营 / 首次登场
- 外观关键词
- 性格关键词
- 核心异能
- 异能限制
- 战斗定位
- 协作对象
- 可操作状态（NPC / 半操作 / 完整可玩）
- 后续成长点

B. 异能文档

每个异能单独一页，固定格式：

- 异能名
- 叙事解释
- 战斗用途
- 非战斗用途
- 触发方式
- 失败表现
- 过载/反噬
- UI 表现
- Demo 是否实现
- 后续可扩展版本

例如林晓：

- 需而生刃
- 当前实现：树枝 / 短刺
- 暂不实现：远程 / 融合 / 稀有武器
- 失败时：生成错物 / 断裂 / 空壳

C. 主线剧情战斗文档

每个主线章节一页，固定结构：

- 章节目标
- 场景
- 进入条件
- 新教学点
- 敌人逻辑
- 玩家输入
- 成功分支
- 失败分支
- 演出点
- 解锁内容

《松鼠大战》

D. 系统文档

这份最重要，但要写得短：

- 核心循环
- 角色选择逻辑
- 联机逻辑
- Bot 填充逻辑
- 副本解锁逻辑
- 版本发布计划
- 数据存档字段

不要一开始写成 80 页。

控制在 10～15 页可执行版本。
