而**唐代形成了成熟的“九品三十阶”品阶制度**，并实现了“官、职、爵、勋”的分离。
### 二、 唐代文官官阶：九品三十阶（文散官）

唐代沿用隋制，采用“九品十八阶”的官品制度，并进一步细分为“文散官”（共29阶，正一品至从九品下，用于表彰官员身份与资历，相当于文官军衔）。

唐代文官体制实现了“寄禄官（散官）”与“职官（实际职务）”的分离：

#### 1. 唐代文散官阶梯（核心代表官衔）

- **超品 / 一品（国之重臣、宰辅荣誉）**
    
    - **正一品**：开府仪同三司（文官最高散官）、太师、太傅、太保、太尉、司徒、司空。
        
    - **从一品**：特进、太子太师/太傅/太保。
        
- **二品 / 三品（宰相与各部尚书）**
    
    - **正二品 / 从二品**：光禄大夫、金紫光禄大夫；中书令、门下侍中（宰相职）。
        
    - **正三品 / 从三品**：银青光禄大夫、朝议大夫；六部尚书、御史大夫、中书舍人。
        
- **四品 / 五品（中层中枢与地方高官）**
    
    - **正四品 / 从四品**：正议大夫、通议大夫、太中大夫；六部侍郎、刺史（上州）。
        
    - **正五品 / 从五品**：朝散大夫、朝请大夫；各司郎中、少监。
        
- **六品 至 九品（中下层官吏与地方县官）**
    
    - **六品 / 七品（中级）**：朝奉郎、承议郎、朝散郎；员外郎、大县县令（京县/上县）。
        
    - **八品 / 九品（初阶）**：宣议郎、将仕郎、登仕郎（最低阶位）；县丞、主簿、尉。
        

#### 2. 唐代文官的四重身份（官、职、爵、勋）

一个唐代高级文官的完整头衔通常由四部分组成：

1. **文散官（本官品阶）**：如“金紫光禄大夫”（从二品，定薪俸与服色）。
    
2. **职官（实际职务）**：如“尚书左仆射同中书门下平章事”（实际掌权的宰相职）。
    
3. **爵位**：如“国公”、“开国县侯”。
    
4. **勋官**：如“上柱国”（战功或政绩勋位）。
