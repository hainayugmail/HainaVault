### 一、 汉代武将序列（武职与官阶）

汉代采用“官品”或“石数”（如万石、二千石）来衡量武官级别。武官系统通常分为**重号将军**、**杂号将军**、**校尉**与**基层军官**四个梯队。

#### 1. 高级重号将军（地位尊崇，多为独当一面的统帅）

- **大将军**：位在三公之上或相等，通常为最高军事统帅，掌全国兵权，多由外戚担任（如卫青、霍光）。
    
- **骠骑将军、车骑将军、卫将军**：地位仅次于大将军，位同三公（位比三司），秩万石。
    
- **四征 / 四镇将军**：征东、征南、征西、征北；镇东、镇南、镇西、镇北将军（东汉及三国时期大量设立），掌管特定区域的征伐与防务。
    
- **四前后将军**：前将军、后将军、左将军、右将军，位比上卿。
    

#### 2. 中级与杂号将军（根据战事临时或专设）

- **杂号将军**：因战事繁多而设立的称号，如伏波将军（马援）、破虏将军（孙坚）、讨逆将军、冠军将军等。
    

#### 3. 禁军与中级实权武官：校尉

- **校尉**：汉代禁军（北军）及边防精锐的核心带兵官，秩比二千石，地位极高（如西汉“北军八校尉”、东汉“北军五校尉”、西域都护府下的戊己校尉）。
    

#### 4. 军中基层梯队

- **军司马**（协助校尉统兵） $\rightarrow$ **军候**（统领一连/一候） $\rightarrow$ **屯长** $\rightarrow$ **什长 / 伍长**。
    

### 二、 唐代武将体制（职官、勋官与散官）

唐代的军官体系非常完善，实行“职阶分离”。一个高级武将的身份通常由三部分组成：**职官**（实际职务）、**散官**（代表军衔品阶）和**勋官**（战功荣誉）。

#### 1. 武散官（最接近现代“军衔”概念）

武散官决定了武将的政治待遇、服饰与薪俸，共二十九阶（从正一品到从九品下）：

|**品阶**|**武散官官称（军衔示例）**|**对应地位/角色**|
|---|---|---|
|**正一品**|建威大将军|军人最高散官品阶|
|**从一品**|骠骑大将军|极品武官荣誉阶|
|**正二品**|辅国大将军|高级统帅级|
|**从二品**|镇军大将军|高级统帅级|
|**正三品上/下**|冠军大将军、怀化大将军|主力兵团统帅/禁军高官|
|**从三品上/下**|云麾将军、归德将军|主力兵团统帅/禁军高官|
|**正四品 / 从四品**|忠武将军、壮武将军、宣威将军等|中级将领、折冲府都尉等|
|**正五品 / 从五品**|游击将军、游骑将军等|中级军官|
|**六品至九品**|仁勇校尉、陪戎副尉等|基层军官/校尉/尉官|

#### 2. 实际武职（职官）

- **中央与禁军**：大将军（如左右羽林军、左右神武军大将军，正三品）、将军（从三品）。
    
- **地方与边防**：
    
    - **节度使**（中后期地方最高军政长官，手握重兵）。
        
    - **都督 / 大都督**（地方军区统帅）。
        
    - **折冲都尉**（府兵制核心，府兵制下各“折冲府”的最高军官，掌管管辖区内的训练与征发）。
        

#### 3. 勋官（战功奖赏）

唐代为奖励军功设立“十二转”勋官，从最高**上柱国**（正二品，战功极高者）到最低**武骑尉**（从七品下）。

### 三、 汉唐对比总结

| **维度**   | **汉朝**                | **唐朝**                      |
| -------- | --------------------- | --------------------------- |
| **核心体制** | 官名即职权，多以“将军/校尉”加上称号表示 | **职官与散官分离**，散官表品阶（军衔），职官表事权 |
| **最高统帅** | 大将军、骠骑将军              | 节度使（地方）、左右羽林/神策军大将军（中央）     |
| **中坚力量** | 八校尉 / 军司马             | 折冲都尉 / 武散官（忠武/游击将军等）        |
| **级别体现** | 石数（如万石、二千石）           | 二十九阶武散官（正一品至从九品） + 十二转勋官    |
