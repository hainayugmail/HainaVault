唐代武官体制与文官一样，实行“官品与事权分离”**的制度。武官的身份由三部分构成：**武散官**（代表军衔与薪俸品级，共29阶）、**实际职官**（具体的指挥领导职务）和**勋官（战功荣誉，最高为上柱国）。

  

以下是唐代中央禁军、地方边防以及军政合一机构中核心武职的职能与品级：

  

### 一、 中央禁军与宫廷卫队（北军与南军）

唐代中央禁军分为**南军**（十六卫，多由府兵轮番宿卫）与**北军**（左右羽林、龙武、神武、神策军等皇帝亲军）：

  

|**部门/军系**|**核心职位**|**职能描述**|**对应品级（职官）**|
|---|---|---|---|
|**十六卫**（左右卫、左右骁卫、左右武卫等）|**大将军**（各卫1人）|十六卫最高长官，掌本卫军令、宫廷宿卫与率领府兵|正三品|
||**将军**（各卫2人）|各卫副长官，协助大将军统领部队|从三品|
|**北军亲军**（左右羽林军、左右龙武军等）|**大将军 / 将军**|皇帝贴身禁军统帅，专掌宫禁禁卫与亲军精锐|正三品 / 从三品|
|**神策军**（唐中后期核心禁军）|**护军中尉**（多由宦官担任）|掌管神策军最高统兵权，中后期掌握朝政大权|从二品 / 正三品|

### 二、 地方军政与边防机构

唐代地方军事体制经历了从前期府兵制（折冲府）**向中后期**募兵制（藩镇节度使）的重大演变：

  

|**机构层级**|**职位名称**|**职能描述**|**对应品级**|
|---|---|---|---|
|**藩镇 / 边防**|**节度使**|边防军区最高军政长官，统领麾下军州，集兵权、财权、行政权于一体|正三品（常加带尚书仆射或同平章事，提升至从二品/正二品）|
||**副使 / 行军司马**|节度使之副手，分管军政文书与军务|正四品 / 从四品|
||**都知兵马使 / 兵马使**|节度使麾下主力部队的实际指挥官|从四品 / 正五品|
|**军 / 守捉 / 镇 / 戍**（边防基层单位）|**军使 / 守捉使 / 镇将**|边境军事要塞与防区的主官，负责边境巡逻与防守|从五品（军使）至 正九品（戍主）|
|**折冲府**（府兵制核心）|**折冲都尉**（上/中/下府）|掌管一府府兵（约800–1200人）的日常操练、征发与宿卫|正五品上（上府）/ 从五品下（下府）|
||**果毅都尉**|折冲府副长官，协助折冲都尉操练部队|从五品上 至 正六品下|

### 三、 武散官阶梯（军衔与身份品级）

唐代武散官共 **29阶**，决定了武官的社会地位、薪俸、服色（三品紫袍、四五品朱袍等）以及随从规格：

  

- **一品至三品（高级将军 / 统帅级）**
    
      
    - **正一品**：建威大将军（武散官最高阶）
        
          
        
    - **从一品**：骠骑大将军
        
          
        
    - **正二品**：辅国大将军
        
          
        
    - **从二品**：镇军大将军
        
          
        
    - **正三品上/下**：冠军大将军、怀化大将军
        
          
        
    - **从三品上/下**：云麾将军、归德将军
        
          
        
- **四品至五品（中级指挥官 / 折冲都尉级）**
    
      
    - **正四品上/下**：忠武将军、壮武将军
        
          
        
    - **从四品上/下**：宣威将军、明威将军
        
          
        
    - **正五品上/下**：定远将军、宁远将军（折冲都尉常带此阶）
        
          
        
    - **从五品上/下**：游击将军、游骑将军
        
          
        
- **六品至九品（基层武官 / 尉官级）**
    
      
    - **六品**：昭武校尉、昭武副尉
        
          
        
    - **七品**：振威校尉、振威副尉
        
          
        
    - **八品**：致果校尉、致果副尉
        
          
        
    - **九品**：仁勇校尉、陪戎副尉（最低阶起家武散官）
