### 唐代“六局二十四司”完整女官品级与职务列表（含低阶品级）

在唐代内廷女官的编制中，不仅有高层的正五品至正六品，每个“司”下方还严格配置了对应的**正七品（典）**、**正八品（掌）**，以及更基层的**正九品（女史）**。

  

下表以“局 $\rightarrow$ 司 $\rightarrow$ 低阶品级（典、掌、女史）”为序，完整呈现各司的岗位及品级分布：

### 一、 尚宫局（总揽文书、人事与统筹）

|**品级**|**官职名称**|**主要职务与职能**|
|---|---|---|
|**正五品**|**尚宫**|六局之首，总领全宫事务、人事考核、传达命令。|
|**正六品**|司言 / 司簿 / 司记 / 司宾|分别掌管谕令宣传、档案图书、文书记录、宾客礼仪。|
|**正七品**|典言 / 典簿 / 典记 / 典宾|协助“司”处理具体的文书起草、档案整理、接待引导。|
|**正八品**|掌言 / 掌簿 / 掌记 / 掌宾|负责日常言语应对、账册登记、笔墨整理、迎送杂务。|
|**正九品**|女史|基层文员，负责抄写公文、日常抄录及基础文牍。|

### 二、 尚仪局（掌管礼仪、乐舞与史册）

|**品级**|**官职名称**|**主要职务与职能**|

|**正六品**|司籍 / 司乐 / 司宾 / 司赞|分别掌管经史图书、音乐歌舞、朝会引导、赞礼唱名。|
|**正七品**|典籍 / 典乐 / 典宾 / 典赞|协助管理书籍、排练音乐、执行礼仪及引导赞礼。|
|**正八品**|掌籍 / 掌乐 / 掌宾 / 掌赞|负责书籍收管、乐器保养、迎宾杂务、仪式帮赞。|
|**正九品**|女史|基层文员，负责经籍抄写、乐谱记录与礼仪文案辅助。|
