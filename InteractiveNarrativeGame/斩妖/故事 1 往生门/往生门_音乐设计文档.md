# 《往生门》音乐设计文档

版本：v1.0
用途：本案（西京林宅·紫苏案）BGM 分层设计、触发时机对照、循环与过渡规则
配套引擎假设：Ren'Py（`renpy.music.play` / `renpy.music.set_volume` + crossfade）

---

## 一、设计原则

1. **分层不分拍**：不为每一小拍单独配曲，而是按"场景功能"归类为 7 组主题音乐，用 crossfade（1.5~3秒）在组间过渡，避免切歌感过于生硬。
2. **同一主题、多种编配**：紫苏的怨气主题（第2组）需要"平静版"与"暴走版"两个编配，本质是同一旋律骨架，情绪走向相反，用于强化"这就是同一个人"的听觉暗示。
3. **幻境音乐要"骗玩家的耳朵"**：第5组（虚假温情曲）表面温暖，但需暗藏极轻微的失真/detune，配合剧情反转时的信息差（"以为赢了，其实没有"）。
4. **符纸/道具音效独立于BGM系统**，作为"信号音"反复出现，形成条件反射，不占用主旋律通道。
5. **音量基准**：BGM 默认 -14dB 左右，人声/独白不静音BGM，但对话密集段落建议动态降至 -20dB（duck）。

## 三、逐拍触发对照表

| 剧本段落 | 触发曲目 | 过渡方式 | 备注 |
|---|---|---|---|
| 第一拍：枯井怨气首次现形 | M2-B（暴走版，弱混音进入） | 淡入 2s | 开场即给玩家"这就是她"的听觉印象，音量压低，不要一上来就炸 |
| 第二拍：初勘（老严/林太太对话） | M1 | crossfade 2s | 全程铺底，体面感与死气感并存 |
| 第一次仓促造梦 | M5 → 反噬瞬间切 M2-B | M5正常播放，反噬前奏突然抽掉底层，只留高频弦乐滑音，随后硬切M2-B | 这是全剧第一次"幻境音乐骗耳朵"的示范，要让玩家记住这个听觉套路 |
| 园丁老刘 / 家政阿姨小翠 / 古玩店老方 | M3 | crossfade 2s | 三段询证共用一曲，避免听觉疲劳；可在老刘/小翠两处各自做细微配器变化（如小翠段加一点水声采样，呼应茶室场景） |
| 山道被跟踪 | M4 | 硬切或极短淡入（0.5s） | 突然性很重要，不要给缓冲 |
| 司机小王三顾 | M3（第一、二次）→ M3+低频心跳叠加（第三次，符力打通心窍瞬间） | 第三次时叠加一层M4的心跳鼓点作为过渡桥段 | 第三次是情绪爆发点，音乐需要比前两次更紧 |
| 起卦锁谎（对老严） | M1（去掉散音，只留drone） | 淡出装饰音 | 强调"撕破脸"的冷峻，不需要旋律性 |
| 第四拍：林耀登门施压 | M4 | crossfade 2s | 保镖交手瞬间可加一记独立的打击乐重音（非BGM，作为音效层） |
| 理想主义成长契机（三选一） | M4 延续，不切歌 | — | 三个选项台词很短，切歌会打断沉浸感，让M4的留白服务这段对白 |
| 法师读取紫苏记忆（走廊/婴儿房片段） | M2-A | crossfade 3s（较慢，营造"顿悟"感） | 这是全剧唯一一处让玩家"共情"紫苏而非"恐惧"她的段落，音乐要柔 |
| 第五拍：抉择准备 | M1（低配器，几乎只剩drone） | 淡入 | 静态思考段落，音乐退到最弱 |
| 第六拍·温和线：孙秘书幻境 | M5 | crossfade 2s | 注意"新房"场景可加入喜庆采样元素（唢呐/鞭炮的失真化处理），增强"表面吉利实则诡异"的反差 |
| 幻境破碎（酒杯摔碎） | 硬切静音 0.3s → M2-A（低音量） | 玻璃碎裂音效独立于BGM，之后1-2秒的绝对静默再进音乐 | 静默本身就是最强的音乐手法，不要用音乐去填这个空隙 |
| 第三次幻境（南洋结局） | M5（变奏，加入更明亮的音色，如木琴/海浪采样） | crossfade 3s | 这是"最甜"的一段，也是反转前最大的糖衣 |
| 婉婉尖叫破局 | 硬切静音 → M2-B（全音量，突然爆发） | 0秒切入，不做淡入 | 全剧最大的一次听觉冲击点，务必硬切 |
| 紫苏冷笑对峙 | M2-A（变调，去掉悲伤感，改为冷硬的持续音） | crossfade 2s | 同一主题但情绪已经"变质"，可考虑升Key或改用不同调式强化"从火变冰"的转变 |
| 结局：往生门拖拽（温和线胜利） | M2-A 渐弱至无 | 5秒长淡出 | 表面胜利的沉默感 |
| 强制线：血战全程 | M6 | 硬切 | 战斗曲不需要铺垫，直接进入 |
| 紫苏被打散 结局 | M2-A（極简版，几乎只剩人声哼鸣） → 淡出 | crossfade 3s | "壮壮"这句台词出现时，建议音乐降到几乎无伴奏，只留人声line，让台词本身成为音乐的一部分 |
| 紫苏彻底黑化蛰伏 结局 | M2-B（低频版，去掉打击乐，只留持续的低频恶意感） | crossfade 3s | 不是消散，是压下去，音乐要传达"还在" |
| 第七拍：结局（温和线专属） | M7 | crossfade 3s | 全案唯一一处"正式结局曲"，不循环，走向渐弱 |
| 结算之后：真相反转（库房活人/紫苏尚在） | M2-A 变奏（去掉所有旋律性，只剩drone+极轻微的敲门声采样） | 淡入，极慢（5s以上） | 这是"细思极恐"式的收尾，音乐要克制到近乎沉默，把恐怖感留给文字和敲门声 |

## 四、信号音效（独立于BGM系统）

这些是短促的音效，不循环，触发时叠加在当前BGM之上，用于建立"听觉条件反射"：

| 信号音效 | 触发场景 | 设计要点 |
|---|---|---|
| 符纸炸开 | 每次贴符/破符 | 短促白噪音 + 高频铃音，全案统一音色，让玩家一听就知道"符在起作用" |
| 玻璃碎裂 | 幻境破灭瞬间（多次出现） | 每次可用同一采样，强化"幻境=脆弱"的听觉标记 |
| 心跳/脉搏声 | 危机逼近、法力将尽 | 低频单音，随剧情推进逐渐加快频率 |
| 敲门声（沉闷、隔水感） | 库房场景、结局揭示 | 处理成低通滤波+混响加长，模拟"隔着门、隔着秘密"的听感 |
| 出手/交手重音 | 保镖交手、血战招式命中 | 一记短促的打击乐单音，不做旋律化处理 |

## 五、Ren'Py 实现建议（技术参考）

```python
# audio.rpy 示例结构

define audio.m1_linzhai = "audio/bgm/m1_linzhai_veneer.ogg"
define audio.m2a_zisu_calm = "audio/bgm/m2a_zisu_calm.ogg"
define audio.m2b_zisu_rage = "audio/bgm/m2b_zisu_rage.ogg"
define audio.m3_inquiry = "audio/bgm/m3_inquiry.ogg"
define audio.m4_threat = "audio/bgm/m4_threat.ogg"
define audio.m5_illusion = "audio/bgm/m5_illusion.ogg"
define audio.m6_battle = "audio/bgm/m6_battle.ogg"
define audio.m7_ending = "audio/bgm/m7_ending.ogg"

# 常规过渡（crossfade 2秒）
play music audio.m1_linzhai fadeout 2.0 fadein 2.0

# 硬切（用于反转/惊吓时刻）
stop music fadeout 0.0
play music audio.m2b_zisu_rage fadein 0.0

# 幻境破碎：先静默再进音乐
stop music fadeout 0.3
pause 1.5
play music audio.m2a_zisu_calm fadein 2.0

# 结局渐弱不循环
play music audio.m7_ending fadein 3.0
# 在该曲目文件本身做淡出结尾，或用 renpy.music.set_volume 配合 pause 手动收尾
```

**循环点建议**：M1、M2-A、M2-B、M3、M4、M5、M6 均需制作成可无缝循环（loop point 对齐节拍），唯独 M7（结局曲）设计为一次性播放、自然渐弱，不循环，强化"这是终章"的仪式感。

## 六、给音乐制作方/外包的简要说明模板

> 项目：视觉小说《往生门》案件BGM
> 风格参考：克制的东方氛围音乐，避免过度"恐怖片配乐"式的夸张音效，情绪需要"表面平静、底层不安"的双层质感。
> 核心要求：紫苏主题需要平静版与暴走版两个编配，共享旋律骨架；幻境音乐需暗藏极轻微失真，为后续揭穿反转做铺垫；结局曲为唯一非循环曲目，需自然渐弱收尾。
> 参考情绪关键词：悬疑、克制的悲伤、体面下的死气、幻境的甜腻危险感、正面对决的爆发力、未完成的余韵。
