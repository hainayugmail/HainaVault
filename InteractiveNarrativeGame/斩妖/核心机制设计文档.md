# 一、核心概念设定

## 1.1 世界观基础命题

斩妖世界的底层规则只有一条:心魔胜过外鬼。妖异本身极少是终极问题所在,真正的病灶永远是人心中的执念、贪婪、迷信、逃避与转嫁。据此,系统需要对"斩妖对象"做出比表面更精细的三层分类:

|   |   |   |
|---|---|---|
|**实体类型**|**定义**|**代表案例**|
|纯人性心魔|完全没有外在妖异实体,病灶就是人心本身|案5·巨婴魔|
|伪妖真人心|表面是妖异害人,深挖后妖异本身清白或情有可原,真恶在人|案3·狐妖阿狸,案4·黄鼠狼族群|
|结构性心魔集合体|由多人(甚至全社会)的共同行为/信仰喂养出的实体,养分来源与复仇目标可分离|案2·抱怨鬼,案6·信愿魔,案8·猫妖|

## 1.2 核心概念定义表

|   |   |
|---|---|
|**概念**|**定义**|
|心魔|由人类情感/欲望长期未被处理而具象化的实体或状态,是斩妖世界里真正的"敌人"原型|
|执念|单一角色未竟的强烈情感诉求,是心魔最基础的驱动单元|
|共鸣|心魔从外部人类情感中持续汲取能量的过程,是心魔维持/成长的机制性描述|
|因果|角色行为与其后果之间的可追溯链条,判定原型据此定位责任归属|
|羁绊|玩家(法师)与可回归NPC之间因单案处理方式而形成的长期态度关系|

# 二、核心变量体系:共鸣值系统

## 2.1 提出动机

现有素材中,案6的"信愿值"与案8的"赎罪值"结构相同、内核相反,而案2的情绪转嫁链、案5的双向共生闭环虽未给出显式公式,但均可归纳为同一种底层机制——心魔的力量来自人类情感与它产生共振后的持续供给。建议将这一底层机制统一命名为共鸣值,并把信愿值/赎罪值/转嫁值/共生值定义为共鸣值的四种子类型("求/赎/推/赖"),而不是四套互不相关的规则。

## 2.2 共鸣值通用公式(提案)

共鸣值(t) = Σ_i [ 情感强度_i × 未解决系数_i × 传播系数_i ]

•     情感强度:该情绪/信仰行为本身的强烈程度(标准化 0~1)

•     未解决系数:1 − 真实问题解决比例 / 真实忏悔程度 / 真实独立程度等,依子类型而定,核心含义是"事情有没有被真正处理"

•     传播系数:该情感行为的扩散广度——单人事件=1;链式传递会随环数累乘(案2);群体信仰会按参与人数加总(案6)

这一通用式的核心含义是:共鸣值从不因为"表面平息"而清零,只有未解决系数真正趋近于0(即问题被真实解决/真实忏悔/真实独立)时,心魔才会自然消散——这正是"断供不等于解决"(案2、案5反复验证)在数值层面的表达。

## 2.3 四种子类型

|   |   |   |   |   |
|---|---|---|---|---|
|**子类型**|**对应现象**|**驱动情感**|**公式(提案)**|**出现案例**|
|求|祈愿/供奉|对未来的盲目寄托|信愿值 = 供奉频次 ×(1−真实问题解决比例)|案6·信愿魔|
|赎|赎罪式供奉|对过去的逃避|赎罪值 = 供奉频次 ×(1−真实忏悔程度)|案8·猫妖|
|推|情绪转嫁链|推卸/不忍独自承受|转嫁值 = Σ链条环数 ×(1−该环情绪消化比例)|案2·抱怨鬼|
|赖|病态依附共生|双向被需要/被照顾|共生值 = 需求耦合度 × 关系持续时长|案5·巨婴魔|

需注意的是,子类型并非互斥,案8·猫妖已经证明"赎"与个体执念复仇可以在同一案件中融合出现,系统应支持多子类型叠加计算同一心魔的共鸣值。

## 2.4 三层变量体系:共鸣值 / 心魔值 / 羁绊值

素材中还出现了明显作用范围不同的另外两个变量——玩家整季行为的"心魔值",以及单个NPC对玩家态度的"羁绊值"。三者应视为三个独立层级,互不覆盖,但存在明确的向上结算关系:单案共鸣值的处理结果 → 影响该案的结局类型 → 结局类型同时写入玩家心魔值(季度总账)与该案相关NPC的羁绊值(角色关系档案)。

|   |   |   |   |
|---|---|---|---|
|**变量层级**|**作用范围**|**更新时机**|**决定内容**|
|共鸣值(案级)|单一案件内的心魔本体|案件推进中随剧情实时波动|心魔的体量、形态、是否临界黑化|
|心魔值(玩家级)|整季玩家(法师)行为总账|每个案件结束时结算增减|终局BOSS体量、可用盟友数量、光明/黑暗结局分野|
|羁绊值(NPC级)|单个可回归角色对玩家的态度|该角色所在案件结束时定档|终局中该角色是盟友/中立/敌对|

心魔值(季末) = Σ_案件[ 假性圆满权重 + 黑化权重 − 圆满解法权重 ] 羁绊值(NPC) = f(该NPC所在案件的结局类型)  // 圆满→高羁绊,警示/假性圆满→低或负,黑化→直接锁定为"终局敌对池"

# 三、通用判定框架整合

案3与案5/案8分别使用了两套具体流派命名(茅山道士/密宗上师/南洋降头师/西方驱魔师;道士/和尚/巫师/阴阳先生)。二者本质上是同一套判定原型在不同案件中的具体化呈现。建议以"判定原型"为统一分类维度,替代具体教派命名,便于系统内自由组合、扩展新流派而不破坏底层规则。

## 3.1 判定原型矩阵(时间焦点 × 介入烈度)

|   |   |   |   |   |
|---|---|---|---|---|
|**判定原型**|**时间焦点**|**介入烈度**|**典型技法**|**误判模式**|
|气运勘测者 (道士原型)|当下表征|温和·非侵入|起卦、八卦盘测气运/煞气纯净度|被旧日残留煞气误导,错判"仍在害人"|
|因果溯源者 (和尚/上师原型)|过去业力|温和·引导式|因果链窥探、经鼓追溯前因后果|被伪装的悔意/眼泪动摇;或说教不给支撑致当事人自厌|
|结果实证者 (巫师/降头师原型)|当下状态|强制·侵入式|血蛊检测、禁忌契约、休克式施压|手段阴邪易激化矛盾;逼迫过猛致崩溃|
|灵魂沟通者 (阴阳先生/驱魔师原型)|不限(直接对话)|居中(视对象配合度)|走阴问询、圣水/信物共鸣|调查不到位时"代言"心愿,一旦拆穿后果更糟|

## 3.2 三段式判定流程

综合全部案例的破案节奏,可提炼出统一的三段式流程,建议作为所有多分支案件的标准结构:

|   |   |   |   |
|---|---|---|---|
|**阶段**|**目标**|**关键动作**|**失败后果**|
|① 勘测|判断异象是否为"心魔"及其表层性质|至少一名判定原型出手,获取初步气运/因果读数|误判为普通邪祟,直接强攻→打草惊蛇或误伤(如案3初期)|
|② 溯源|定位心魔的共鸣值子类型(求/赎/推/赖)与首恶/无辜边界|线索收集(物件/日记/证词)+ 二次验证(建议2种以上判定原型交叉核实)|溯源不全→精准清算变成和稀泥,埋下假性圆满伏笔|
|③ 审判|在"结局模板"中选择解法路径|依据溯源结果执行:造梦/宣泄引导/精准清算/长期处方等|选择与真相不符的解法→触发黑化或警示结局|

## 3.3 联合判定机制(降低误判率)

每种判定原型都存在明确的误判盲区(见3.1表"误判模式"列)。建议引入联合判定机制:同时使用两种及以上判定原型对同一心魔进行交叉验证,可显著降低误判率(如案3中四流派各自独立验证,结论高度一致)。但联合判定会消耗额外时间/资源,而黑化机制(见第四章)存在窗口期递减压力——这构成了"求稳"与"抢时间"之间的核心策略张力,建议作为关卡设计的主要抉择点。

# 四、黑化机制详细设计

## 4.1 定义

黑化 = 心魔或受害灵体因未获得及时的公正回应或遭受二次伤害,情感由"悲痛/怨恨"不可逆转化为失控复仇状态的过程。黑化是系统里唯一被明确标注为"不可逆"且会"污染后续案件"(成为跨案BOSS原型)的失败结局类型,应作为最高优先级的警示机制单独设计。

## 4.2 黑化值公式(提案)

黑化值 = Σ(伤害事件强度 × 二次伤害系数) − Σ(有效安抚/公正回应值)  阈值(t) 随案件推进动态递减  // 拖延判定 = 窗口期收窄,呼应案4"抢时间"设计

二次伤害系数是黑化值飙升的关键放大器——初次伤害(如案4老祖丧孙)本身尚可通过精准清算挽回,但若叠加欺骗式安抚被拆穿(案1紫苏)、首恶未受惩罚(案4结局二)、粗暴道德追讨(案5休克疗法、案8和尚线警示)等二次伤害,黑化值会指数级上升而非线性叠加。

## 4.3 黑化四阶段

|   |   |   |   |   |
|---|---|---|---|---|
|**阶段**|**心理状态**|**外部表现**|**是否可逆**|**典型案例节点**|
|Stage 0 悲痛期|克制、仍愿讲道理|托梦致歉、送礼求和(老祖)|完全可逆|案4·老祖初次现身送山货赔礼|
|Stage 1 怨恨积累|信任崩解,窗口期缩短|妖气/煞气开始外溢,出现零星报复|可逆,需及时干预|案4·勒索绑架后老祖再次现身对峙|
|Stage 2 临界点|理智与疯狂的最后拉锯|山巅/废墟级正面对峙,法力剧烈碰撞|最后窗口,仅精准清算/真诚沟通可挽回|案4·法师与新任首领山巅斗法|
|Stage 3 完全黑化|彻底吞噬,不可逆|屠村/实体化为跨案BOSS|不可逆|案4结局二;终局黑暗结局的信愿魔完全实体化|

## 4.4 黑化的三类子机制(须严格区分)

素材中"变坏"其实包含三种性质不同的失败状态,不应混为一谈,建议在系统中作为三条独立判定分支:

|   |   |   |   |
|---|---|---|---|
|**子机制**|**触发方式**|**结果性质**|**案例**|
|受害者黑化|长期无人回应的悲痛 + 二次伤害(首恶未清算)|永久质变为加害者,成为跨案BOSS原型|案4结局二;案8猫妖终局若失败|
|转移宿主|心结未被真正消融,仅表面症状缓解|本体未必黑化,而是问题'复发',寄生新宿主/新关系|案5结局三·巨婴魔转移到未来伴侣关系|
|延迟埋雷|找替罪羊/交易式解决,回避真正责任人|表面平息,新怨种潜伏,成为未来案件伏笔|案4结局三·献祭式和平;案8交易式和解|

## 4.5 黑化的跨案传播规则

•     完全黑化的角色进入"黑化NPC池",在后续案件中以固定或随机方式作为新BOSS登场(如案4结局二"新一代妖王反派原型"),其起源可作为后续案件的可调查回忆线索。

•     转移宿主与延迟埋雷不进入黑化NPC池,而是作为"隐藏种子"随机触发全新的、表面无关的新案件(即该心魔原型换皮重生,如巨婴魔在恋人关系中复现)。

•     终局(结局篇)本质上是黑化机制在游戏尺度上的极限推演:若玩家整季心魔值过高,则紫苏、黄皮精首领、柳树精、猫妖会集体转入"敌对/黑化阵营",与信愿魔、抱怨鬼、黄粱魇合流,形成结局篇黑暗结局的"五方恶念"——证明黑化机制不仅作用于单案,还直接决定终局阵营归属。

## 4.6 干预设计原则

•     窗口期递减:每延后一次有效干预,后续干预所需的"有效安抚值"应相应提高,制造真实的时间压力。

•     干预烈度需匹配阶段:Stage 0~1 宜用温和引导类原型(道士/和尚系),Stage 2 临界点必须依靠"精准清算+真诚沟通"组合拳,任何阶段使用强制侵入类原型(巫师/降头师系)处理心理创伤类心魔都应显著提高触发"二次伤害型黑化"的概率,以呼应案5、案8对"休克疗法""过度追讨"的明确警示。

•     黑化不等于战斗力提升的爽点设计,而应作为叙事与结局层面的惩罚性后果,符合全系列"暴力手段是下策"的一贯基调(序章强行打散=卡关)。

# 五、整合结算公式(提案)

将以上三章内容串联,给出终局判定的整体计算逻辑,供后续数值策划校准:

单案结局类型 = f(共鸣值子类型是否被正确溯源, 判定原型选择是否匹配阶段, 黑化值是否越过阈值)  玩家心魔值(季末) = Σ_案件[ 结局类型对应权重 ]  该案NPC羁绊值 = 结局类型对应固定增量(圆满>0, 警示≈0或轻微负, 假性圆满≈0, 黑化=锁定为敌对)  终局分支 = f( 玩家心魔值, 已黑化NPC数量, 已建立正向羁绊的NPC数量 )   → 心魔值低 且 正向羁绊NPC数量≥阈值  →  光明结局   → 心魔值高 或 黑化NPC数量≥阈值      →  黑暗结局(恶念时代)

**该整合公式的核心设计意图是:玩家在单案中的每一次判定选择,既是当案的叙事分支,也是在为终局的"审判天平"投票——这正是全系列"心魔胜过外鬼"命题在数值系统层面的最终落点:游戏真正评分的,从来不是玩家打赢了多少场战斗,而是玩家在多少次面对人心时选择了诚实与耐心。**

- **数值机制**：报警 → `justice_value +10`、`corruption_risk -5`；不报警 → 数值不变，直接进原结局。两个变量分开写，不共用一个字段，方便你以后接入现有的黑化/正义系统。
- **分屏背景的戏剧作用**：没有让报警变成一个"纯粹变好"的选择——右半边警员通风报信给老严这个细节，暗示西京的关系网没那么容易被一份笔录捅穿，报警在数值上是"正确"的，但剧情上留了一个隐患（消息可能已经先一步传回林家），呼应之前beat sheet里"结局要留不安感"的建议，而不是让这个选择变成简单的"选好人加分"。
-
