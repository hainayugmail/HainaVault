# 案三修订：刺猬精"魏大妈"支线整合设定

> 本文档整合近几轮讨论定下的新增设定，作为对《故事 3 狐影：雷劫与人心.md》正文的修订依据。正文尚未按此改写，改写时可参照本文档的拍位对应关系逐段替换/插入。

## 一、反派设定：魏大妈（刺猬精）

- **表面身份**：步行街摆摊算命的"乡下大妈"，黑瘦干瘪，姓魏。手法是街头冷读——蹲守人流量大的地方（奶茶店旁），随口给路过的人"看相"，靠观察反应现场编故事。
- **真身**：刺猬精，四大门"白仙"一支。
- **能力**：吸取福泽根基——不是直接吸命/吸血，而是吸干他人积攒的福泽/气运底子，事后表现为破财、倒霉、绝嗣一类的慢性伤害，很难第一时间查到源头。对应她真实身份"看家聚财"的刺猬习性（囤粮过冬 → 囤积他人的福泽）。
- **与阿狸的旧怨**：阿狸早年撞见她毫无底线地吸食人的福泽根基，看不下去，出手教训过她一次。两人自此结怨——这也侧面说明阿狸自己虽有过采补的污点，但始终守着一条底线，因此见不得魏大妈的毫无节制。
- **目标**：算准阿狸即将渡劫，图谋在渡劫最混乱的一刻浑水摸鱼，夺走阿狸三百年修为，用来助自己渡劫。
- **行动风格**：蓄谋已久、精于算计，不是临时起意的路人妖。她早就盯上了阿狸渡劫的时间点，也摸清了沈明这个软肋，一步步设局，而不是靠运气撞上。

## 二、开场重构（对应第一拍）

1. **奶茶店冷读（刻意安排，非巧合）**：魏大妈在奶茶店给一个陌生姑娘看相，说她印堂发黑，男朋友在吸她精血，教她初一十五跟踪男友。这场戏是她算准了沈明会在旁边买奶茶、刻意讲给旁人听、实则说给沈明听的一出戏，利用他对阿狸"初一十五吃素上山还愿"这个习惯本就有的模糊疑虑，把种子种下去。
2. 沈明起疑，某个十五的夜里执意要陪阿狸一起上山"还愿"。
3. 当晚阿狸如常给他用了安神香，自己按月度惯例出门。刺猬精用嗅盐将他唤醒，他醒来只看见墙角缩着一只小刺猬，阿狸已经不见——他悄悄跟出旅馆房间。
4. 山中，他看到阿狸现出原型，在山坳里独自打坐调息——**这是她每月固定的私人仪式，为一个月后的真正终劫做准备，不是终劫本身**。"初一十五吃素上山还愿"这个说法因此是双关：表面是敬佛的托词，实际是她压制、打理妖元波动的月度功课。
5. 沈明吓坏，佯装无事。次日回到步行街，找了八九天才找到魏大妈。
6. 魏大妈"解读"他的遭遇，坐实他的恐惧，却故意摆出"这种大妖我治不了"的低姿态——越是推说自己无能为力，越是把狐妖形容得可怕（已能化人形、会吸干精血），吊着他往下问，最终喂给他"吃了狐妖元神能长生不老、容颜不老"这个饵，怂恿他去请真正的法师收妖。

> 这样处理让沈明的黑化保留了他自己的责任：他先是真的害怕（亲眼所见，不是被骗出来的幻觉），之后才被魏大妈利用了这份恐惧和随之而来的贪念。

## 三、法师登场与调查阶段（对应第二至第四拍）

- 沈明的密信发给四位真正的法师：**道士、和尚、出马仙、教会驱魔师**（取代此前草稿中的茅山道士/密宗上师/降头师/驱魔师组合，需在后续改写中同步替换相关台词与判定手法，见下方"四法师改写对照"）。
- 魏大妈全程隐身，若有若无——街坊、药铺老掌柜、黑市线人等各路NPC口中都"听说有这么个大妈"，但没人真正见过她本人，问不出实质线索。
- 四位法师各自的感知手段（起卦、观因果、请仙问事、圣器感应等）都能查到"妖气"，但因为魏大妈藏得极深、气息内敛，没人意识到现场其实叠着两股妖气——只当是阿狸自身气息有些异常波动，误判为渡劫将至的正常征兆。
- 刺猬精本人在暗处观察四位法师的判断进度，等待时机——她的存在感只停留在传闻层面，直到终劫夜才现身。

## 四、终劫与摊牌（对应第五至第六拍）

- 一个月后，阿狸的真正终劫如期而至——这次才是"再过一道雷就是人了"的那场终极雷劫，场景与氛围可沿用原稿老宅庭院那场戏。
- 四位法师依次亮明判断、与沈明摊牌、各自散去（原稿四法师退场戏的骨架可以保留，台词按新阵容调整）。
- 真正的混乱时刻——众人散去、雷劫降临、阿狸妖元因散功散被削弱到极限——魏大妈趁乱现身，图谋夺取阿狸三百年修为。这是她蓄谋已久的收网时刻，也是整案第三层真相（幕后另有其妖）揭晓的时间点。

## 五、法师抉择（贯穿第五、六拍）

法师的决定**只影响阿狸和魏大妈的结局，不影响沈明**——沈明的因果走向是固定的（见下）。两道独立判断：

1. **对阿狸的态度**：主动出手相助她渡劫成功 / 保持中立不插手（默认走向，接近原稿）/ 受沈明或魏大妈蛊惑而对她不利。
2. **对魏大妈的处置**：当场铲除 / 识破阴谋但放走（留因果伏笔）/ 被劝说心软放过 / 被魏大妈开出的条件（分修为/法力）收买合谋。

四位法师的天然倾向（可作为对话/立场设计参考）：

- **道士**：按门规行事，查清阿狸近年无过便按下不理；对魏大妈偏向镇压收服，不轻易赶尽杀绝。
- **和尚**：慈悲优先，倾向劝双方放下执念；劝魏大妈大概率失败，但这份"劝不动"本身能强化"人心比妖更难渡"的主题。
- **出马仙**：与四大门体系有说不清的亲疏关系，是唯一可能从"自己人"渠道拿到独家情报、也唯一可能被魏大妈拉拢或施压的法师——她的仙家谱系里刺猬精的白仙地位不算高，出马仙对付起来包袱较小，但也可能生出"自己人何必赶尽杀绝"的心软。
- **教会驱魔师**：对两个"异端"妖物本能上都倾向清除，但一旦认定阿狸确已洗心革面，会是维护她最坚决的一个——教义本身承认"悔改"。

## 六、结算与伏笔

- **心魔值 / 主角黑化风险值**：按上述两道判断结果累计，沿用现有结算体系。
- **案件羁绊值·阿狸**：沿用原稿"不在场·可再逢"。
- **案件羁绊值·魏大妈**（如未被当场铲除）：新增"未清算·可再逢"——为后续案件埋线索，她可能带着抢来的部分修为、或换一副更谨慎的伪装重新出现。
- **沈明结局**：不受法师选择影响，维持原稿"镜中狐面"因果自负的走向——法师能改变的只有妖，改变不了人心已经做下的选择，这是本案想突出的落点。
