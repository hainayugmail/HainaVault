## 二、二性格底色对白节点

【节点1：张大爷 - 询问神秘女子体貌特征】
温和委婉："大爷，方才您说沈明车里那位姑娘，不知您可还记得她生得什么模样？也是想跟您对对，免得认错了人。"
直接了当："那姑娘长什么样，你说说，我好核实身份。"
NPC统一回答："记得。"张大爷放下剪刀，"穿得很精致，戴个金表，车是她的不是沈明的——沈明每次都是坐副驾。"他停了一下，"我这把年纪看人看得出来，那不是一般的朋友。"
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点2：张大爷 - 追问对话（解锁条件：已从其他NPC处得知林筱身份）】
温和委婉："大爷，后来打听到，那位姑娘许是林家的小姐——只是想跟您确认一下，阿狸这些年，可有跟旁的什么人走得近？"
直接了当："那姑娘是林家的，城南那家地产的千金。阿狸这边呢，有没有跟旁人不干净的地方？"
NPC统一回答：他皱起眉头，"那个沈明，我说他最近往那边跑什么，原来是这么回事。"他摇了摇头，"他家那个阿狸，这三年里我没见过她跟别的男人有什么往来。沈明倒是……唉。"
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点3：药铺老掌柜 - 询问药方蹊跷之处】
温和委婉："掌柜的，劳您费心——这张方子搭配起来，是不是有什么不对劲的地方？您给掌掌眼。"
直接了当："这方子配得有问题吧？说说哪里不对。"
NPC统一回答："那个方子单独看没问题，可这几味药搭配在一起……"他指着底方上的几个字，"我行医这么多年，从没见过这样配方子的——这几味互相冲克，这哪是治病，分明是拿身体当战场厮杀……我实在看不懂。"（法师随后自行判断出这是专用于妖体的慢性散功方子，不受问法影响）
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点4：黑市掮客老马 - 确认散功散委托记录】
温和委婉："老马，劳您行个方便——半个月前，是不是有人托您打听过散功散这味东西？我不为难您，只想知道是谁。"
直接了当："半个月前，有人托你打听散功散，是谁？"
NPC统一回答：老马沉默了片刻，然后从外衣内袋摸出一封叠起来的信，"他当时附了一封信——说是让我转给他联系上的法师，让法师看了再报价。我留了一份存底。""这行里的规矩是两不相问，但他这封信……"他把信推过来，"太明显了。我不是没见过想借刀杀人的，但这么写出来的，不多。"（获得关键线索「密信存底」）
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点5：管家王叔 - 追问劝阻小姐的原因】
温和委婉："王管家，冒昧问一句——您方才说建议小姐别再见沈明，不知是因为什么，方便说说吗？"
直接了当："你劝小姐别见他，为什么？说重点。"
NPC统一回答："因为他同时在做两件事。一件是追小姐，另一件是在安排什么——具体查不到，但他最近调用了一笔钱，走的是现金，没有流水。""法师，不管那只狐妖有没有问题——沈明这个人，你自己掂量。"
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点6：法师 - 点破茶叶罐里的干扰物（第四拍）】
温和委婉："沈先生，不必紧张——茶叶罐里那点东西，贫道已经看出来了。你若说清楚原委，这事还有转圜的余地。"
直接了当："你的茶叶罐里放了什么？老实说。"
NPC统一回答：沈明的脸色变了一下，"什么？"——随后法师用本门手段径直探出实情（内丹、老马、林筱、干净），不受问法选择影响，剧情照常推进到沈明图穷匕见的那段。
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

【节点7：法师 - 最后劝告沈明收手（第四拍）】
温和委婉："沈先生，贫道把话说明白——她这三年没害过一个人，再有一个月便能渡劫圆满、彻底脱身。你若肯收手，体面分开，或者什么都不做，由她把这最后一道劫渡完、自行离去，这件事便到此为止，谁也不欠谁，你还来得及回头。"
直接了当："她这三年没害过人，再一个月就渡劫圆满，跟你再无瓜葛。你现在收手，或者什么都别做，这事就算完——自己选，别逼我把话说第二遍。"
NPC统一回答（沈明的反应固定，不因法师问法而变）：沈明的眼神晃了一下，那一瞬间确实动摇过，但只是一瞬间——想到已经花出去的现金、黑市那边的存底、林筱，还有"延年益寿、容颜不老"，恐惧和贪念拧成了更硬的东西。"我不管什么圆满不圆满！她是妖！吃了我三年的阳气，现在轮到我吃回来了——法师，你要是不肯帮我，自然有别人肯！"
（温和委婉选择 → trait_idealist+1；直接了当选择 → trait_rebel+1）

## 三、行动抉择点（与二性格问法无关，剧情本身会真正分叉，原文已是完整分支写法，此处仅列位置不改写台词）

**抉择点A（第四拍）：法师对沈明的态度**
四选一：完全抽身版 / 动武版 / 睁眼闭眼版 / 暗中留守版。直接决定第六拍开场时法师是否在场、以及沈明会不会当晚再摸上山。

**抉择点B（第六拍，仅暗中留守版触发）：魏大妈初次动手时，法师要不要现身**
四个理由二选一走向不同：门规 / 判她终究是妖 / 两妖相争不该插手人类之外的事——这三项都续接「④/⑤分支」；"她没犯过大错，见死不能不救"这一项续接「⑥完整助阿狸线」。

**抉择点C（第六拍，④/⑤分支内）：法师要不要反杀阿狸**
二选一：「人妖殊途，灭掉这个三百年大妖」→ ⑤反杀阿狸；「放过阿狸，阿狸并无大错」→ ④护人不护妖。这一步是全案黑化值的直接触发点，无论最终追没追上、杀没杀成，只要选了反杀，黑化值都+1，并埋下"法师·执念魔"的隐藏伏笔。
