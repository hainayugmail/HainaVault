# 一、主角设定

## 1.1 性别

主角性别可任意选择(男/女),仅影响立绘、称谓等表现层内容,不触发任何剧情分支、台词差异或NPC态度差异。全部案件文本、结局判定、结盟机制均与性别无关,系统内部统一以"主角"处理文本变量,避免维护两套剧情分支。

## 1.2 门派(五选一)

主角需在开局从道士、和尚、出马仙、巫师、教会驱魔师五个门派中选择一个作为初始身份（未来可以增加风水阴阳先生）。门派选择决定:

•     初始判定视角与技能树(见第二、三章)

•     在特定案件中的天然优势/劣势(与自身门派对口的案件判定更容易一次成功,不对口的案件更依赖联合判定或道具辅助)

•     是否在特定案件解锁"结盟"选项(见第六章——若主角本身就是该案对口门派,则不产生外部结盟NPC,而是以"同门"身份直接参战该案)

•     终局初始出场身份与专属奥义(主角本人门派天然参与终局战,不需要通过结盟解锁)

# 二、五大门派详解

五门派在判定原型矩阵基础上扩展而来:道士与和尚沿用原有"气运勘测者/因果溯源者"定位;"灵魂沟通者"原型拆分为出马仙(东方·请仙走阴)与教会驱魔师(西方·圣礼审判)两支独立门派;巫师沿用"结果实证者"定位。

|   |   |   |   |   |   |
|---|---|---|---|---|---|
|**门派**|**判定原型**|**焦点/烈度**|**核心手法**|**门规底线**|**形象基调**|
|道士|气运勘测者|当下表征·温和非侵入|起卦观气、符箓布阵、镇灵铜钱|不滥杀无辜,但斩一切邪祟|刚正、程序化、略执拗|
|和尚|因果溯源者|过去业力·温和引导式|因果链窥探、经鼓渡厄、责任重构|慈悲为怀,重因果转念不重惩罚|宽厚、耐心、易被悲情动摇|
|出马仙|灵魂沟通者·东方|不限·居中(视配合度)|请仙上身、走阴问询、与亡灵直接对话|先问心愿,后问对错|民间、直率、重情义|
|巫师|结果实证者|当下状态·强制侵入式|禁忌契约、蛊虫/血祭、结果导向施压|不问过去,只认当下有无恶念残留|阴冷、务实、不讲情面|
|教会驱魔师|灵魂沟通者·西方/审判|不限·居中偏强制|圣水共鸣、圣经银钉、契约审判|神圣契约与绝对审判|肃穆、原则性强、易陷教条|

# 三、法术系统设计

## 3.1 法术分类框架

全部门派共享同一套五分类框架(侦测/封印/战斗/沟通/疗愈),但各门派在每一类别上的具体表现手法不同,且擅长类别不同(如道士偏侦测+封印,和尚偏沟通+疗愈,巫师偏战斗,教会驱魔师偏封印+战斗,出马仙偏侦测+沟通)。

|   |   |   |
|---|---|---|
|**法术类别**|**作用**|**举例(跨门派通用逻辑)**|
|侦测类|判断异象性质、勘测心魔类型与共鸣值子类型|起卦、佛眼观因果、走阴问询、圣水共鸣(对应四大判定原型)|
|封印/压制类|临时约束心魔行动,为调查争取时间窗口|结界、镇灵符、金刚怒目相、禁锢契约|
|战斗类|临界点/黑化阶段的正面对抗手段|天罡伏魔阵、降魔剑意、蛊虫噬咬、圣银钉审判|
|沟通类|与心魔/亡灵直接对话以获取真相或达成谅解|请仙上身、入梦术、走阴对话|
|疗愈/收束类|案件后期的心结化解与长期调理|造梦、桃木人替身宣泄、诵经处方、责任重构引导|

## 3.2 技能分级:基础技 / 进阶技 / 奥义

每个门派的技能树分三级,消耗与威力递增,呼应第五章"递进的斩妖系统":

|   |   |   |   |
|---|---|---|---|
|**门派**|**基础技(常用)**|**进阶技**|**奥义(高消耗/剧情级)**|
|道士|镇魂符、避秽诀、破煞咒|天罡伏魔阵、雷击木剑|太极卦盘照乾坤(一次性揭穿全场谎言)|
|和尚|清心偈、避秽结印|嘎巴拉鼓唤心灯、因果全景观照|渡厄金身(强制中断黑化倒计时一次)|
|出马仙|上香引魂、通灵低语|请仙上身、走阴问询|三生对谈(让心魔与其执念对象隔空对话)|
|巫师|禁忌契约小术、蛊虫探查|阴阳血蛊、休克式施压契约|以命换命(高风险高回报的终极契约,可能反噬自身)|
|教会驱魔师|圣水泼洒、十字禁言|驱魔圣经共鸣、黑芒审判|圣银钉终判(对"纯粹人心之恶"必定命中,对心魔本体无效)|

# 五、递进的斩妖系统

参照系统设计文档中"心魔位阶"的三重递进结构,建议将其正式转化为五级难度曲线,作为关卡解锁与角色成长的双重依据:

|   |   |   |   |   |
|---|---|---|---|---|
|**位阶**|**规模特征**|**对应案例**|**所需法术等级**|**对应道具解锁阶段**|
|Ⅰ 个体执念|单一角色,无外部供养|序章、案1|基础技即可|查验类基础道具(符纸、镇魂符)|
|Ⅱ 群体结构|多人共谋/共生,无明确单一元凶或元凶与无辜混杂|案2、案4、案5|进阶技解锁|替身法器、观影镜、罗盘|
|Ⅲ 存在级/双层融合|结构喂养+个体执念融合,审判难度最高|案8|进阶技+至少一次联合判定|全部查验类道具|
|Ⅳ 社会信仰级|全社会规模,自我繁殖|案6、案7|奥义解锁|至亲信物级关键道具|
|Ⅴ 主线终局级|三位一体合流,跨案角色总动员|结局篇|全部奥义+羁绊值达标|全部道具+盟友技能池|

## 5.2 角色成长四轴

•     判定精度轴:通过反复练习/联合判定降低误判率,解锁"一次判定即命中"的效率加成

•     法术等级轴:基础技→进阶技→奥义,决定可处理的心魔位阶上限

•     道具解锁轴:查验类道具广度决定溯源效率,消耗类道具储备决定战斗/疗愈容错率

•     人脉羁绊轴:即结盟系统积累的跨门派羁绊值,直接决定终局可用战力(见第六章)

# 六、门派结盟系统(核心机制)

## 6.1 规则总纲

斩妖世界共存在五大门派。主角只能选择其一作为自身身份,但其余四个门派的代表人物会分别在与该门派"天然契合"的案件中以NPC身份登场。若主角本身不是该案的对口门派,系统会开放"结盟"选择;结盟成功与否将被记入该NPC的羁绊值,并直接决定其是否在终局出手相助。

## 6.2 已确定的三组绑定关系

|   |   |   |   |
|---|---|---|---|
|**案件**|**天然契合门派**|**结盟触发条件**|**结盟效果**|
|案6·信愿魔|和尚|主角非和尚时,可选择与和尚NPC结盟|结盟成功记入该NPC羁绊值,终局解锁和尚助战席位|
|案7·美梦魇|道士|主角非道士时,可选择与道士NPC结盟|结盟成功记入该NPC羁绊值,终局解锁道士助战席位|
|案4·黄鼠狼精|出马仙|主角非出马仙时,可选择与出马仙NPC结盟|结盟成功记入该NPC羁绊值,终局解锁出马仙助战席位|

你目前给出的三组绑定已覆盖和尚、道士、出马仙。为保持五门派结构对称(每个门派都应有至少一个专属结盟入口),提出以下补全建议:

|   |   |   |   |
|---|---|---|---|
|**案件**|**天然契合门派**|**契合理由**|**结盟效果**|
|案1·绛珠血衣|巫师|全案核心是"以私人物品为媒编织庞大因果幻境"的高阶禁忌秘术,与巫师的契约/仪式风格天然契合|结盟成功可提高"幻境不被拆穿"的判定成功率,直接影响紫苏终局是敌是友|
|案8·猫妖|教会驱魔师|全案核心是道德审判与忏悔真伪辨别,教会驱魔师"圣水/黑芒可识别纯粹人心之恶"的设定天然契合|结盟成功可提升甄别"赎罪型"虚伪供奉与"冤执型"真实忏悔的准确率|

_提案(非原设定,供确认): 若你已为巫师、教会驱魔师安排了其他案件或不需要凑齐五门对称,可直接忽略本节,系统仍可仅以三组绑定运作,只是终局助战席位上限相应为"主角本人 + 最多3位结盟NPC"。_

## 6.4 终局机制:五门归一

若五组绑定全部启用且主角在每个非本门案件中都选择并达成结盟,终局战可集结"主角本人门派 + 四位结盟门派使者"共五方力量,对应五大门派全部到场——这是数值与叙事双重意义上的"满配"结局,呼应结局篇光明结局中紫苏、黄皮精首领、柳树精、猫妖等角色回归的团圆感,但提升到了门派/阵营层面的团圆。

终局可用助战数 = 1(主角本人门派,天然参战)                  + Σ_四个非本门案件[ 是否成功结盟 ? 1 : 0 ]  理论上限 = 5(集齐全部门派);理论下限 = 1(全部拒绝结盟或结盟失败,单人硬撑终局)

## 6.5 关键平衡设计要点

•     同门不触发结盟:若主角本身就是某案的对口门派(如主角是和尚,则案6无"结盟"选项),该案改为"同门位面"——由主角亲自以该门派身份处理此案,不产生外部NPC名额;为避免玩家因此错过隐藏福利,建议在该案设置"同门认可度"作为平行奖励通道(如获得该门派专属进阶技提前解锁,而非终局助战席位)。

•     拒绝结盟不阻断主线:结盟应设计为可选分支,拒绝或结盟失败仍可通关该案(可能触发更高难度的独立判定,或该案更容易滑向警示结局/假性圆满),但会永久失去该门派在终局的助战席位。

•     结盟≠无条件成功:结盟本身可设置为一次小型判定或好感度积累过程(例如需要联合判定成功率达标),避免"结盟"沦为无脑加分选项,保持与主线判定框架的手感一致性。

•     结盟NPC应带来的是差异化技能而非数值加成:每位结盟门派使者在终局提供的应是其专属奥义的一次性使用权(如教会驱魔师的圣银钉终判专克"纯粹人心之恶"型残留反派),而非单纯的攻击力/血量加成,以保持"心魔胜过外鬼"命题下"手段匹配而非数值碾压"的解题逻辑。
