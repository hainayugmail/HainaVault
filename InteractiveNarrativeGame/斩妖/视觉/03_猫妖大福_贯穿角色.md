# 角色设定卡 · 疫爪猫妖 / 大福（贯穿角色·案八→终局）

## 基础信息

| 项目 | 内容 |
|---|---|
| 本体 | 大福，三岁橘猫，四斤半，张晓禾三年前捡回来的流浪猫 |
| 死因 | 疫情期间被强制"无害化处理"（带走后村口传来焦糊味，暗示被烧毁） |
| 核心执念 | 想知道张晓禾松手时，心里有没有它——不是复仇，是想要一个真实的答案 |
| 三种形态 | 见下方详细拆解，务必分开做三套立绘 |

## 形态一：生前（回忆/闪回画面用）

**原文依据：**橘猫，三岁，四斤半，"脾气温吞、见谁都要用脑袋蹭一蹭的肥猫"

普通橘猫形象，圆润肥胖，性格温顺画面感强烈——用于开场闪回、结局篇彩蛋等温情场景。

## 形态二：疫爪猫妖（第四拍现形·主要战斗/对峙形态）

**原文依据（重点参考段落）：**

- 体型：**"体型像一座小山"**（巨大化）
- 毛皮：**"惨白的消毒水色"**（不是正常猫毛色，是病态的漂白色）
- 双眼：**"燃烧着幽绿的鬼火"**
- 爪子：**"透着寒光"**
- 身上缠绕**黑色铁链**（锁猫笼的链条演变而来，"是它的一部分，不是束缚它的，是它用来记住的"）
- 眉心处有**橘色斑记**（这是识别它就是大福的关键细节，务必保留）
- 声音设定：无数猫叫声混合成的人声（视觉上可以用"张开嘴时有多重叠影/回声波纹特效"来暗示）

## 形态三：终局登场（安静的白猫，执念平息后）

**原文依据：**
- "不是最初那副庞大、暴戾、满身消毒水气息的疫爪形态——只是一只安静的、瘦小的白猫"
- 落在混凝土台上，绿色眼睛平静
- 结局篇里最后是"轻巧地落下来"、"用那双眼睛，平静地把整个战场扫了一遍"

这个形态体型恢复正常（甚至偏瘦小），毛色变白（不再是"消毒水的惨白病态"，而是干净的白），眼神从戾气转为平静，铁链和鬼火全部消失。
