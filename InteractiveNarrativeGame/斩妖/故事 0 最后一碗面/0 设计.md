
## 设计目标对照表

| 教学目标       | 在这个案子里怎么实现                       |
| ---------- | -------------------------------- |
| 调查/收集线索    | 3条明显线索,无隐藏支线,找完就能推进              |
| 正面交锋失败     | 快速演出,30秒以内,不做重伤动画                |
| 诊断执念类型     | 单一原因,无歧义                         |
| 造梦/二选一抉择   | 一个节点,两个选项,结果直观                   |

| 识破值/共鸣值存在感 | 隐性出现但不解释数字,只靠画面反馈让玩家感知到"选错了会有问题" |

## 一、案件背景

**地点**:老城区一栋六层居民楼,二楼,刘婆婆的家。

**案情**:刘婆婆,七十三岁,退休厂工,独居。三周前在厨房里安静地去世,因为没有亲人常来探望,三天后才被邻居发现。死因是心脏病突发,没有外力介入,法医结论清晰。

但从上周开始,整栋楼的住户都说二楼飘出奇怪的香味——是葱花爆锅的味道,深夜尤其浓。有人在楼道里碰见一个穿着洗得发白的碎花围裙的老太太,跟她打招呼,她只是笑笑,转头就消失了。

门打不开,邻居报警,警察进去发现屋里没有人,但炉子上放着一口锅,锅里有一点点干掉的汤底。

**厉鬼**:刘婆婆本人。没有杀气,没有恨意,甚至不知道自己已经死了。她在厨房里来来去去,反复做同一件事:煮一碗面,等一个人来吃。

---

## 二、调查阶段(目标:找到三条线索)

**整体基调**:屋子很整洁,但有一种"为某件事做了很久准备,事情却一直没发生"的感觉。

**线索一:冰箱门上的便利贴**

```
便利贴上写着,字迹有点颤:
"小军买了火车票,腊月二十八到家。
记得买猪骨,熬汤底,他爱吃打卤面。"

日期是三个月前。
```

提示玩家:她在等一个叫"小军"的人回来过年。

**线索二:客厅茶几上的手机**

手机是老年机,屏幕裂了一道缝。未接来电显示:

```
"小军" × 14次(最近一次:三周前,下午两点)
```

系统里只有两个联系人:小军,和一个存成"120"的号码。

提示玩家:她死前小军一直在打电话,她没接到。

**线索三:厨房里的锅**

锅里有面条,但没有煮熟——水烧开了,面放进去了,然后一切就停在了这里。炉子旁边放着一个搪瓷碗,碗里提前放好了葱花、芝麻和猪油,就等面条出锅。

```
[玩家检查炉子]
系统提示:
燃气已经关掉了。不是她关的——是警察来了之后关的。
这碗面,到最后也没有出锅。
```

提示玩家:她是在煮面的过程中猝然离世的,最后的心愿就是这碗面。

---

## 三、正面交锋(30秒演出,快速带过)

调查完三条线索后,刘婆婆从厨房里走出来——她看起来很普通,围裙,白发,笑眯眯的,但整个房间的温度骤然下降了十度,玩家角色的法器开始有轻微的反应。

她没有扑过来,只是站在那里,用一种完全不知道对方在做什么的眼神看着玩家角色,然后走回厨房继续煮面。

但当玩家角色尝试靠近或施法时——

她回过头,眼神没有任何变化,还是那种慈祥的笑,但在那一瞬间,整栋楼的灯全灭了,玩家角色被一股看不见的力量推了出去。

```
[玩家角色摔在门口]
独白(根据门派变化):
道士:"这不是恨。这是什么……"
和尚:"这股怨气毫无杀意。她根本不知道我在这里。"
阴阳先生:"……她以为自己还活着。"
巫师:"有趣。她不是在困住别人,她只是在等人。"
```

---

## 四、诊断执念(门派各自的判定方式)

重伤(轻微,几秒后恢复)后,玩家角色在门口做出判断:

|门派|判定手法|诊断台词|
|---|---|---|
|道士|摇签|"签文:『守候』。等候之人未归,执念成形。她在等谁。"|
|和尚|默念|"她的业未了——不是恶业,是一碗还没喂出去的心意。"|
|阴阳先生|倾听|凑近门缝,听见锅里的水滚了又凉,凉了又滚。"她不知道她死了。她以为小军还在来的路上。"|
|巫师|牌|翻开一张牌:『等待者』,正位。"她在等一件还没发生的事完成。"|

四种判定方式结论相同:执念是"一碗没有送出去的面"。

解法:让她相信,那碗面送出去了。

---

## 五、造梦阶段(核心教学节点)

玩家进入幻境,幻境场景是刘婆婆的厨房——但这次一切都是暖的,灯亮着,锅里的水在正常地滚。

刘婆婆在灶台前,背对玩家角色,她在等面条熟。

**教学节点一:她发现了"小军"的影子**

玩家需要选择让幻境里的"小军"以什么方式出现:

```
选项A:直接推开门走进来
选项B:先敲了敲门
```

这道选择没有对错,但会影响后续细节(这是教玩家"选项不是随机的,是根据你调查到的线索来判断的")——线索二显示小军打了十四个未接来电,他是一个着急的、担心妈妈的人,他一定是先敲门。所以选B,共鸣值小幅上升;选A,无影响但也无惩罚(这是教学关,容错率高)。

**教学节点二:小军喊了什么**

"小军"走进厨房,刘婆婆回过头——这里玩家需要选择让幻境里的小军说什么:

```
选项A:"妈,我回来了。"
选项B:"妈,面好了吗?我饿了。"
```

这是整个教学案里唯一真正考验玩家"有没有在认真看线索"的时刻——线索一便利贴上写的是"他爱吃软一点的面",刘婆婆煮面之前提前放好了葱花和猪油,她的执念核心不只是"等人回来",而是"让他吃上一口热面"。所以选B("我饿了"这句话直接触发了她煮面这个动作的意义),共鸣值明显上升;选A也可以过,但后面需要多一个步骤。

**核心演出:面出锅了**

刘婆婆把面捞进那个搪瓷碗里,浇上猪油,撒上葱花,转过身递给小军。

```
她笑了。
"趁热吃,软了不好吃。"
```

这是整个游戏里唯一一句需要用中英双语都写得足够温柔的台词。

## 六、结局演出(圆满)

碗从"小军"手里慢慢消散——幻境开始柔和地瓦解。

刘婆婆站在那里,看着空了的碗,再看看窗外——窗外不是那栋六层楼的街道,而是很远很远的什么地方,天光正好。

```
她摘下围裙,叠好,放在灶台上。
"吃完了。"

她没有消散,她走向了那扇窗——然后越过了它。
厨房里的灯,最后灭了一盏。
只有搪瓷碗还在桌上。空的,干净的。
```

**案件结算**:

```
案件:《最后一碗面》
执念:化解
厉鬼:往生

解锁:先机道具×2 / 门派熟练度+1 / 调查技能简介
```

结算画面后,一行小字:

```
[真实记录]
刘婆婆的儿子刘军,在她去世后第五天赶到了西京。
他在厨房里看见了那个搪瓷碗。
他不知道为什么,他哭了很久。
```

## 七、失败分支(教学性失败,轻量处理)

如果玩家在节点二选了A("妈,我回来了"),而且前面节点一也选了A(直接推门),双重"没读线索"会触发一次**轻量失败提示**:

幻境里的小军坐下来,但没有说想吃面,刘婆婆看了看锅,又看了看小军,手搭在锅盖上——然后停住了,眼神开始变得空洞,幻境的边缘出现一丝裂痕(识破值轻微上升的视觉化)。

系统轻提示(不打断节奏,画面角落微微发光):

```
〔法器有些不稳——也许可以再想想,那碗面对她来说意味着什么〕
```

然后给玩家重选这个节点,不重置整个造梦阶段——这是教学案,不做真正的失败惩罚,但让玩家第一次感受到"识破值"这个东西确实存在,会有画面反馈。

## 八、文案总字数与时间估算

|阶段|台词/文字量|体验时长|
|---|---|---|
|调查三条线索|约300字|5-6分钟|
|交锋演出|约80字(含门派变体)|1分钟|
|诊断|约60字(含门派变体)|1分钟|
|造梦两个节点|约200字|4-5分钟|
|结局演出|约150字|3-4分钟|
|结算画面|约60字|1分钟|
|**合计**|**约850字**|**约15-18分钟**|

体量符合"20分钟以内"的教学案定位,有足够余量给美术动效和节奏停顿。

案0已完成,T002可以勾掉了。这个案子和《凶宅·友谊》之间的情绪落差是刻意的——刘婆婆知道的,是面可以解决的事;紫苏不知道的,是朋友还活着。这个对比如果能被玩家感受到,开篇三小时的情绪弧线就成立了。

这个设计很聪明——**在进门之前先给玩家一次"无压力的符纸实战"**，让他们建立起"符纸=正确解法"的肌肉记忆，然后进了刘婆婆家之后法器突然不对劲，反差感才能真正建立起来。而且这个路遇厉鬼还能承担世界观科普的功能，不需要额外的教学弹窗。

我把这段路遇写成完整的过场文案，四个门派各有一个版本的独白，但核心演出共享。

#### 场景设定

法师接案后，步行前往刘婆婆所在的居民楼。傍晚，路灯刚亮，街上还有零散的行人。快到楼栋入口的时候，法师在楼道外的转角停下来了。


---

### 这段演出的设计意图

这段路遇在整个开篇流程里承担了五件事:

**建立肌肉记忆**——符纸/法器用起来了，玩家知道这是"正常操作"，后面刘婆婆屋里法器反应异常才能形成对比。

**世界观科普**——用最轻松的方式告诉玩家:死了没多久的普通孤魂是什么状态(没有执念、没有恶意、只是迷路了)，对应"符纸层"的典型案例，之后三层分层就有了参照系。

**四门派性格初登场**——每个门派在这段独白里的语气已经很不一样:道士是职业化的平静、和尚是因果式的淡然、阴阳先生是接地气的市井感、巫师是冷静观察的智识感——玩家在选完门派之后,第一次真正感受到"这个角色是什么人"。

**情绪基调校准**——格子衬衫男的塑料袋、没吃上的花生米、"我媳妇今晚做红烧肉"——这些细节让"死亡"这件事在游戏里第一次出现时不是惊悚的，而是带着一点日常的、让人鼻酸的温度，和刘婆婆的案子的情感基调完全匹配。

**强行符纸打散刘婆婆的代价对比**——如果玩家后来在刘婆婆那里也选择了强行符纸打散，可以在心魔值+的提示旁边加一行极小的注脚:"格子衬衫男是自己明白了。刘婆婆不是。"——不说教，让玩家自己体会两件事的差异。
