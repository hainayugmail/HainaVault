版本：v1.0

配套引擎假设：Ren'Py（`renpy.music.play` / `renpy.music.set_volume` + crossfade）

## 〇、与《往生门》的关系说明

**沿用（系列统一层，建立"同一个法师"的听觉品牌）：**
- 符纸/起卦音效（炸符声、起卦提示音）——全系列统一音色，不做变体
- 结算画面BGM（显示心魔值/黑化值等跨案数值时）——全系列统一，作为UI反馈音

**不沿用（本案怪物属性与紫苏完全不同，需要独立设计）：**
- 紫苏主题（M2-A/M2-B）——紫苏是有名有姓、有悲剧根源的个体怨鬼，音乐核心是"人味的悲伤"；牢骚煞是无本体的情绪网络，音乐核心应是"失控的均质感"与"蔓延感"，两者混用会让玩家的听觉记忆错乱
- 幻境曲（M5）——本案不涉及"造梦入幻"的机制，不需要"表面温情、底层不安"这套骗耳朵的设计

**风格基调差异：**
《往生门》是古风山宅、个体悲剧、有形怨鬼；《牢骚煞》是现代都市、群体性心理病灶、无形网络。音乐上要从"箫/古筝/人声哼鸣"的东方氛围，转向"电子脉冲/机械重复/多层叠加"的都市工业感，避免案二听起来像案一的续集。

---

## 一、设计原则

1. **它不是"一个鬼"，是"一张网"** —— 牢骚煞没有面容、没有固定形态，靠情绪链条寄生蔓延。所有音乐设计都要围绕"叠加感"展开：同一段旋律用不同音色分层叠入，对应链条上不断增加的受害者，而不是给它一个类似紫苏那样的"专属旋律主题"。
2. **均质感即恐怖感** —— 陈曼监控录像里"没有情绪起伏、像在念清单"的自言自语，是本案最核心的听觉意象。全案基调曲需要一种"过分规律、过分平淡"的机械重复质感，取代传统配乐的旋律性抒情。
3. **不做"骗耳朵"的幻境音乐** —— 本案没有造梦机制，不需要糖衣包装的温情曲。取而代之的是"证词层层累积"的悬疑推进感。
4. **结局是开放的、未完成的** —— 案一温和线结局是"平静下的沉重"，本案结局却是"个体问题解决了，但网络还在，且有人在背后收集数据"。收尾曲需要更冷、更工业感，为系列后续（信愿魔前置线索）留出听觉钩子。

## 四、N3"情绪之网·叠加层"分层触发说明（本案核心技术设计）

这是本案与《往生门》最大的结构性差异：紫苏是单一旋律主题的两种编配（平静/暴走），而牢骚煞是**同一段极简动机的多层叠加**，模拟"链条上受害者越来越多"的过程。

**建议做法：**
- 设计一段极简的2-4小节循环动机（比如一个简单的电子琶音或人声念白片段）
- 制作6个音色变体，分别对应六个角色的"情绪注入"：王建国、李梅、秦悦、赵树海、周洋、陈曼
- 每揭示一段链条关系，就在原有基础上叠加一层，音量、音色逐渐复杂化，但节奏骨架不变
- 到"证词冲突记录本满3条"和"牢骚煞现形"两处，六层全部叠满，制造"过载"听感
- 技术实现上可以用 Ren'Py 的多轨 channel 分别控制每层的音量渐变，而非切换整曲

```python
# audio.rpy 示例：N3 分层触发（伪代码逻辑）

define audio.n3_layer_wang = "audio/bgm/n3_layer_wangjianguo.ogg"
define audio.n3_layer_li = "audio/bgm/n3_layer_limei.ogg"
define audio.n3_layer_qin = "audio/bgm/n3_layer_qinyue.ogg"
define audio.n3_layer_zhao = "audio/bgm/n3_layer_zhaoshuhai.ogg"
define audio.n3_layer_zhou = "audio/bgm/n3_layer_zhouyang.ogg"
define audio.n3_layer_chen = "audio/bgm/n3_layer_chenman.ogg"

# 各层各占一个独立 channel，循环播放，初始音量为0
init python:
    renpy.music.register_channel("n3_wang", mixer="music", loop=True)
    renpy.music.register_channel("n3_li", mixer="music", loop=True)
    # ... 以此类推

# 揭示某段关系时，将对应层音量从0渐变到目标值
renpy.music.play(audio.n3_layer_li, channel="n3_li", fadein=3.0)
renpy.music.set_volume(0.6, channel="n3_li", delay=3.0)
```

## 五、信号音效（沿用系列统一版本 + 本案新增）

| 信号音效 | 触发场景 | 备注 |
|---|---|---|

## 六、给音乐制作方/外包的简要说明模板

> 项目：视觉小说《牢骚煞》案件BGM（系列第二案）
> 与前作关系：本案怪物设定与前作（往生门·紫苏）完全不同——紫苏是有悲剧根源的个体怨鬼，本案的"牢骚煞"是无本体的情绪网络，靠寄生蔓延。因此音乐风格需从"东方氛围+人声哼鸣"转向"电子脉冲+机械重复+多层叠加"，不要沿用前作的配器逻辑。
> 核心要求：需要一段可拆分为6层音色的极简循环动机（N3），用于表现"链条受害者逐渐增加"的叠加过程；核心音色标签"均质低语"（N2）需要传达"平淡到诡异"的机械感，而非传统恐怖片式的尖锐音效；结局曲（N7）需要设计成"逐渐融入城市环境噪音、而非明确终止"的开放式收尾。
> 参考情绪关键词：都市冷感、机械重复、信息过载、寂静式恐怖、未完成的悬而未决。
