来源：直接从当前代码 `DemonSlayer/game/character_creation.rpy`（变量声明与注释）+ 抓取
`ascension_trial_investigate/climax.rpy`、`complain_investigate.rpy`、`gate_of_rebirth_investigate/dream.rpy`、
`dalumian.rpy` 里对这些变量的实际读写点，整理出"现在真的在用"和"已声明但还没案子用上"两类。

## 一、语气/性格类（四选一问法，跨案件累加）

不算"结局判定"变量，但决定主角的性格底色标题（结算画面/最终结局用），且是后续三条"行动类"值
的判定基础（选语气 = 顺带累加对应人格值，不重复计分）。

| 变量 | 含义 | 目前接入的案子 |
|---|---|---|
| `trait_idealist` | 理想主义者：共情强、天真、执着、道德要求高 | 案3渡劫（8处语气选择）、案2牢骚煞（3处） |
| `trait_pragmatist` | 实用主义者：理性、冷静、算计、缺乏安全感 | 案2牢骚煞（3处） |
| `trait_loner` | 敏感独行者：清醒、内省、易碎、习惯用疏离/讽刺自我保护 | 案2牢骚煞（3处） |
| `trait_rebel` | 激进反叛者：热血、冲动、不服输、对秩序和命运充满怒气 | 案3渡劫（8处）、案2牢骚煞未见 |

正负极性（`polarity_idealist/pragmatist/loner/rebel`，None/"positive"/"negative"）由每个人格
自己的主线"渡劫节点"单独判定并锁定，不受后续案子的语气选择影响。四个人格哪个是"当前主导"
可以一直变，但极性一旦在juncture触发时锁定就不会再改。最终称号查 `PERSONA_NAMES`（如
理想主义+positive="坚定守护者"，理想主义+negative="绝对审判官"）。

## 二、跨案件声誉值（结局判定核心）

| 变量 | 含义 | 加分 | 减分 | 目前接入的案子 |
|---|---|---|---|---|
| `corruption_value`（黑化值） | 法师手段有多脏，跨案件累计 | 招式越狠分越高（沿用各案 forceful_battle 系列的+5/+15/+20或简单场景+1）；打散"没犯过错"的妖/鬼额外+`CORRUPTION_INNOCENT_BONUS`(=20) | — | 案3渡劫climax（+1/+3）、案2牢骚煞（+1两处）、案1往生门（+1两处）、案1的dream线（+5/+15/+20三处、大分值场景）、dalumian（+1） |
| `justice_value`（正义值） | 是否主动伸张正义 | 惩罚犯错人类/帮被欺负的妖鬼 | 明知有错却袖手旁观、放过该追究的人真的会扣分 | 案3渡劫climax（+1三处）、案2牢骚煞（+1两处）、案1往生门（+1两处，报警/沉默±10）、dalumian（+1） |
| `CORRUPTION_THRESHOLD`（常量=60） | 黑化值到这个阈值，会在合适节点弹出`check_corruption_ending`一次性抉择，选"守住底线"就正常return，选"不再分辨"就直接锁定黑化结局【戮妖罗刹】并return——不会带着"已黑化"状态进入后续案子 | | | 实现在character_creation.rpy，任何案子的climax/结算节点都可以call它 |
| `reported_lin_family` | 只记录案1往生门报警/沉默这一次抉择具体选了哪支，给后续案子引用"当年被林家追杀还是打压"用；**不能用justice_value正负反推**，因为justice_value是持续累加值，这次抉择前后还有别的+1零星加分 | | | 仅案1往生门 |

## 三、行动风格类（各自独立轴，互不共用，理论上还能扩展）

| 变量 | 含义 | 目前接入的案子 |
|---|---|---|
| `trait_resolve`（刚毅性格） | 语气选直接粗鲁（沿用trait_rebel，不重复计）+ 明知有更稳妥打法依然选跟终局关键威胁正面拼到底、不留后路 | 仅案1往生门dream线（1处，+1） |
| `spirit_favor`（妖精助力值） | 语气选温和委婉（沿用trait_idealist，不重复计）+ 跨案件反复选"先给妖/鬼一个机会、不赶尽杀绝"。给机会的选项+1，"不留情面"选项不扣分（沿用惯例）。**大结局第三浪"五人反噬"判定直接用这条：终局时`spirit_favor`<30%，紫苏/黄皮精首领/柳树精/疫爪猫妖/阿狸五人无视各自案子里帮没帮过TA，直接倒戈心魔一方** | 案2牢骚煞（1处）、案1往生门dream线（3处） |
| `trait_sacrifice`（牺牲精神） | 明知有更安全的选项，依然为了救人（哪怕对象是妖魔）拿自己安全去冒险 | 仅案1往生门dream线（2处） |
| `human_severity_value`（面对恶人） | 对所有作恶人类角色（不限于最终反派）宽严与否，数值越高代表越不肯轻易放过 | 仅案1往生门investigate（2处，±1各一次） |
| `fairness_value`（人妖立场公正度） | 人的利益 vs 妖/鬼利益直接冲突时的立场，正数偏人类负数偏妖鬼；**需要案子专门写一个选择点才会被喂到，目前代码里一次都没用上** | **目前0处，已声明但未接入任何案子** |
| `caution_value`（谨慎值） | 面对未明朗局面，是按下冲动暂缓观察、还是立刻正面应对；数值越高越倾向先观察后行动。**明确不是"胆小/懦弱"的贬义评分，只记录决策风格** | 目前**仅1处**：案3渡劫climax第242行，+1 |

## 四、大结局（西京决战）专用机制（还没转成.rpy代码，来自终局文档设计说明）

这两条不在character_creation.rpy里，是大结局正文档`故事 结局.md`末尾设计说明里定的，转rpy时
需要新建变量：

- `finale_helpers`：字符串列表，静默记录"这个案件角色/门派是否被真心帮过"，决定终局第二/四浪
  谁会出现在帮手名单里，不显示在结算画面。
- `betrayal_list`：字符串列表，静默记录"这个案子的妖/鬼要不要作为旧怨加入心魔方"，触发条件是
  这个案子结算时①选择把它"打得魂飞魄散" 或 ②`spirit_favor`当时<30%（按当时数值，不随后续回升移出）。
  决定终局第三浪具体有几个"旧怨"（`len(betrayal_list)`）。

终局四浪清点：心魔方（三魔头+betrayal_list旧怨+`spirit_favor`<30%触发的五人倒戈）vs 法师方
（核心四人+finale_helpers里的门派/角色）。法师方多→自爆·长眠；心魔方多→黯然倒下，按第三浪
是否触发五人反噬分"反省"/"戮妖罗刹"两档；黑化值单独在`check_corruption_ending`分出"戮妖罗刹"
这个独立的黑化坏结局分支（跟终局四浪清点的"戮妖罗刹"同名但触发条件不同，两处要注意区分，
转rpy时最好换个名字避免混淆）。

## 五、当前状态小结

- **重度使用**：`corruption_value`、`justice_value`——每个已实现的案子（案1/2/3/dalumian）都在用，是唯一两条"每案必接"的值。
- **中度使用**：`spirit_favor`——3个已实现案子里2个在用，且是大结局唯一直接消费的跨案件值。
- **轻度使用（1处）**：`trait_resolve`、`caution_value`——各自只在一个案子的一个节点触发过，属于"声明了但基本没怎么用上"。
- **完全未使用**：`fairness_value`——声明了，注释写明"需要专门选择点"，但目前代码里一次都没接。
- **口味/风味类，不直接判定结局**：`trait_idealist/pragmatist/loner/rebel`及其极性——决定人格称号，不直接进入终局四浪的加减法。

（还有4个案子——案4屠窝、案5信愿魔、案6金蚕蛊、案7/8——目前还没有对应的.rpy实现文件，
它们各自的设计笔记里可能提到会接入哪些值，但代码层面还没发生，这里不重复列。）
