### 案件核心创意（从最初构思保留至今，仍是这个案子的灵魂）

## ✅ 已写入正文：小事引发血腥屠杀的完整升级链条

8. 黄鼠狼当晚报复，既咬伤了东东本人，也咬死了邻居家的鸡
9. 邻居气愤，当晚就纠集堂兄弟在后山下了夹子、铁丝套
10. 两只黄鼠狼中招受伤（一只断尾逃脱，一只被勒死），族群彻底被激怒，从零星偷食变成成群结队报复性偷鸡
11. 水坝改道、补偿彻底落空，村民积压已久的怨气找到出口，全部倒向黄鼠狼
12. 村民开始主动追打、下夹子、把活捉的黄鼠狼吊在村口示众
13. 黄鼠狼族群彻底被激怒，村民组织青壮进山捣毁黄鼠狼的窝——法师及时示警，大部分黄鼠狼逃脱，但老弱幼崽还是死伤惨重
14. 白毛老祖压住想复仇的青壮，主动托梦向村长求和，送上山参灵芝等赔罪
15. 赵三起了贪念，设陷阱抓了十几只黄鼠狼吊起来勒索更多"宝贝"
16. 老祖带着最疼爱的幼孙下山谈判，混乱中幼孙被赵三扔出的猎刀刺死

## 三轮交锋数值机制设计（2026-09-30 设计，⚠️ 全部尚未写入正文）

### 涉及的数值轨道

- `corruption_value`（黑化值）、`justice_value`（正义值）——跨案件全局变量，角色创建脚本里已声明
- `human_severity_value`（面对恶人）——跨案件全局变量，专门针对赵三/王婆/投毒村民这类人类作恶者
- `fairness_value`（人妖矛盾公正度）——跨案件全局变量，目前全游戏还没案子挂过，屠窝是第一个挂载点
- `village_trust` / `weasel_trust`——**本案专属局部变量**，只用来判定这一案走结局一/二/三哪一条，不跨案件持久化。⚠️ 概念上不是单纯的"喜不喜欢法师"，而是"信不信法师镇得住场面"——所以强硬/展现实力的选择（报警从重、斗法获胜）可以提振这两个值，单纯温和公正但没有实际压制力的选择，反而可能让某一方觉得法师指望不上。
- `weasel_leader_bond`——**本案专属、但跨案件持久化**的单一 NPC 好感值，仿照紫苏（`zisu_mercy_count`）的先例，专供未来大结局"帮手名单"判断黄鼠狼首领愿不愿意出场帮忙

### 局部变量声明与结局判定

```renpy
# ---------- 故事4屠窝专属：本案信任值（本案内累加，不跨案件）----------
default village_trust = 0
default weasel_trust = 0

# ---------- 阈值常量（首次预估，待playtest调整）----------
define WEASEL_TRUST_COLLAPSE = -6   # 黄鼠狼一方彻底失望 → 结局二
define VILLAGE_TRUST_COLLAPSE = 1   # 村民对法师失去耐心 → 结局三（"低于等于"触发）

# ---------- 跨案件持久化：黄鼠狼首领对法师的具体好感，供未来大结局"帮手名单"判断 ----------
default weasel_leader_bond = 0
```

```renpy
label story4_ending_check:
    if weasel_trust <= WEASEL_TRUST_COLLAPSE:
        $ story4_ending = "ending2"
        jump ending_leader_corrupted
    elif village_trust <= VILLAGE_TRUST_COLLAPSE:
        $ story4_ending = "ending3"
        jump ending_scapegoat
    else:
        $ story4_ending = "ending1"
        jump ending_peaceful_resolution
```

判定顺序：黄鼠狼那边先判——首领彻底心死是最激烈的失控，优先级压过村民那边的动摇。

**✅ 已确认的设计哲学（不是bug，是故意的）**：全程只选"一视同仁/公正"一侧，`weasel_trust`会冲到+9，但`village_trust`会跌到-1、触发`VILLAGE_TRUST_COLLAPSE`——这个结果被用户明确保留了下来，而且很喜欢这种失衡感：**一味的善良公正，反而压不住任何一边**。真正能稳定走向结局一的打法，不是靠态度温和公正，而是要在两边各用一次"实力压制"——对村民用节点六的报警/从重处理，让他们知道再乱来要付代价；对黄鼠狼用结局一自带的"巅峰斗法"，用实打实的修为把首领打服。公正只是态度，实力才是让态度真正落地、让两边都愿意听法师说话的资本。玩家如果只走"温和讲道理"这条路，两边表面上都不反对，实际都不会真正服气。

这个设计哲学对数值有一处直接影响：**节点六的`village_trust`方向需要重新校准**——"从重处理"这个选项现在应该是提升`village_trust`（村民看到法师真的敢让人担代价，反而更信他镇得住场面），而不是原稿里的-1；"法律上的事我不插手"这个选项则应该扣`village_trust`（村民会觉得法师软弱、指望不上，为后面"自己动手"埋雷）。具体改法见下面节点六的更新版本。

### 黄鼠狼首领——未来大结局"帮手名单"判定

```renpy
define WEASEL_BOND_THRESHOLD = 3   # 首次预估，待整体数值平衡后再调

label finale_check_weasel_ally:
    if story4_ending != "ending1":
        # 结局二首领已黑化成猩红修罗/未来大妖王，结局三首领基本没和法师建立信任，
        # 这两条线不检查帮手资格
        return

    if weasel_leader_bond >= WEASEL_BOND_THRESHOLD and justice_value >= 0 and corruption_value < CORRUPTION_THRESHOLD:
        $ weasel_leader_will_help = True
    else:
        $ weasel_leader_will_help = False
```

三重门槛：
- `weasel_leader_bond >= 3`——这一案里，法师有没有让首领本人真正感受到被公正对待（本案专属，不受其他案子影响）

- `corruption_value < CORRUPTION_THRESHOLD`（沿用已有的60）——法师本人还没有滑向"戮妖罗刹"那个不分善恶的黑化终局

`WEASEL_BOND_THRESHOLD = 3`和`justice_value >= 0`这两个数字都是先给的估值，等大结局那边"帮手名单"的整体设计（其他案子NPC的门槛都定下来）之后应该会再校准一轮，不建议现在写死。

## ⚠️ 尚未写入正文：结局余韵——首领暗中夺气运的诅咒

不管最终走向结局一、二、三的哪一条，黄鼠狼首领在案子结束时，都会不顾自身修行根基，暗地里取走河湾村的气运——这是首领在明面之外留的一手，玩家不一定能当场察觉。

## ⚠️ 尚未写入正文：节点六·报警抉择——误伤保护动物之后

在双方互相伤害的过程中，黄鼠狼（属于"三有"保护动物）被大规模捕杀的事被意外捅到了明面上——几个动手最凶的村民被警方带走。玩家面临一个两难：

**报警/放任警方处理**：村民本就不富裕，被抓走的人要么关几天要么赔钱，等于在已经很艰难的日子上再补一刀——雪上加霜。可即便真的抓了人，黄鼠狼一族也不会觉得讨回了公道：不过是"关几天、赔点钱"，跟死去的族人比起来，怎么算都是村民吃得亏更少，黄鼠狼依然觉得自己吃了亏。

**不报警/不追究**：村民在人类社会里是弱势的一方，可站在黄鼠狼面前，他们手里的猎枪、夹子、人多势众，反而是压倒性的强者——黄鼠狼一族已经死伤惨重，村民却还是不解气，继续往死里逼。

两条路都没有真正让任何一方满意——这正是这个案子想讲的"人妖矛盾公正度"（`fairness_value`）最尖锐的一个体现：法律意义上的"处理"和情感/族群意义上的"了结"，根本是两件事。

**正因如此**，黄鼠狼首领最终选择不再等一个"公道"的说法，而是直接找法师斗法——法师必须拿出真正压得住场面的实力，才有资格坐下来谈判。这一点已经完整体现在正文结局一的"巅峰斗法"那一段（法师镇压首领后，才用观影镜摆事实、走正规司法程序处置赵三一伙），报警抉择可以看作是这场斗法"为什么必须打"的前因。
