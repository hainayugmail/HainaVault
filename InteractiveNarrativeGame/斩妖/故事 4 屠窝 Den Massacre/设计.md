### **没有单一反派,而是一场双方都在互相"喂养恶念"的群体冲突**。而且这案子里藏着一个特别关键的细节。

### 案件:《屠窝》

**河湾村**,六岁孩童追赶一只黄鼠狼,黄鼠狼被逼至墙角回身呲牙自卫(未曾真正伤人)。孩子受惊,当晚发烧说胡话——本可能只是普通惊吓发烧,却被村人传成"被黄皮子摄了魂"。父母听信谣言,连夜纠集村民,挖了村口的黄鼠狼窝,四处追打黄鼠狼。黄鼠狼的首领托梦求和，还给村民送了山里的礼物，村民贪欲起，抓了10几只黄鼠狼吊起来威胁黄鼠狼首领，让她们月月进攻，结果再对峙中失手杀了后山首领的孙子。打死一整窝黄皮子——其中包括从不害人、修行多年的黄皮子"老祖"和几只幼崽。后山的黄皮子族群闻讯下山复仇,不分青红皂白地报复村民,一场村庄与黄皮子的战争爆发,双方均有死伤。法师受邀入村平息战事。

之前的"屠窝"版本核心矛盾是"双方都有责任",这次改编后**责任天平明显倒向村民**,但恰恰因为如此,反而制造出两个更精细的判定问题:
![[Pasted image 20260722060847.png]]
**1. 追责精度:惩首恶,还是罪连全村?**  
绑架勒索十几只黄鼠狼多半是村里几个贪心的带头人主导,并非全村共谋。如果黄皮子复仇不分青红皂白屠村,那它就从"讨回公道"滑向了自己也在造孽——这时候门派要做的不是简单站队,而是**帮首领精确指认真凶,把复仇范围限制在该负责的人身上**,防止无辜者(比如从未参与绑架的普通村民)被殃及。

**2. 受害方的黑化风险:首领会不会也变成怪物?**  
首领此前展现过极大的克制和诚意(主动托梦、送礼求和),这次悲剧对它来说是"以德报怨换来丧孙之痛"——这个心理落差比单纯的复仇动机更容易催生真正的黑化。如果门派处理不当,**首领本身可能从这案子的"讲道理的一方"变成新的反派**,这是"屠龙少年变恶龙"第一次落在非人角色、而且是"受害者"身上,比之前案例更有冲击力。

### 四门派新走法

||判定重心|具体手法|关键抉择|
|---|---|---|---|
|**道士**|起卦追责,分辨主谋与从众,同时诊断首领心神是否已现"心魔"征兆|力主"只惩首恶不累无辜",用符箓稳住首领心神,防止悲愤攻心|若误判追责范围(比如错误地要求首领只惩戒一人却漏了真正主谋),复仇会因不公再度爆发|
|**和尚**|直指首领的哀痛本身才是最大风险,先超度亡童再谈追责|用类似案1的"造梦"手法,让首领在幻境中与孙儿好好道别,防止其被丧亲之痛吞噬理智|如果和尚只顾抚慰首领而拖延追责,主谋可能趁机脱罪或毁灭证据|
|**出马仙**|现实主义路线,直接跟村里谈判换取集体平安|用契约手段"交出真凶,换全村免于报复"——本质是把一个人推出去抵罪|这是全案道德争议最大的方案:牺牲个体保全集体,正义吗?即便真凶罪有应得,这种"献祭式解决"本身也可能埋下新的冤魂|
|**驱魔师**|走阴问亡童本人的遗愿,而非猜测首领该怎么做|用孩子的真实心愿去影响首领的选择——这里可以埋一个反转:亡童临死前的心愿也许不是复仇,而是不希望祖父因此蹚浑水、毁了数百年道行|如果调查不到位,驱魔师可能"编造"了一个亡童本不曾有的遗愿去说服首领,一旦被识破,首领会彻底失去对人类的信任|

![[Pasted image 20260722060947.png]]

**三条结局**:

- **圆满**:真凶被精确惩戒,首领在悲痛中被稳住没有黑化,只惩首恶、不累无辜,黄皮子与村庄勉强达成新的边界
- **首领黑化**:门派没能及时安抚首领,它在丧孙之痛中彻底黑化,变成不分善恶的复仇修罗,屠戮全村——这是本案独有的"受害者黑化"结局,后续甚至可以让这个黑化的首领成为其他案件里出现的新反派原型
- **献祭式和平**:出马仙方案得逞,表面平息,但被推出去抵罪的人如果本身也有冤情(比如只是被主谋胁迫参与),会留下新的怨气种子,为连锁案件埋伏笔

这个改编版本我觉得比原来的更锋利——它把"人心的恶"从"恐慌"升级成了"贪婪辜负善意",而且第一次让**非人角色也面临黑化的抉择**,这对你整个"心魔"世界观是个很好的补充:恶不分人妖,谁都可能在剧痛中被噬恶魔吞噬。

## 三轮交锋数值机制设计（2026-09-30 补充）

> 以下内容对应现行正文（编号场景式调查 + 第一轮恐惧/第二轮报复/第三轮复仇/终局前夜 结构），和上面这份早期构思（四门派/出马仙/驱魔师版本）已经是两套不同阶段的设计——早期构思保留作历史记录，不要拿来覆盖下面这套。下面这套数值机制尚未写入 rpy，具体阈值都是首次预估，等真正开始转代码、跑通几次 playtest 之后应该会再校准。

### 涉及的数值轨道

- `corruption_value`（黑化值）、`justice_value`（正义值）——跨案件全局变量，角色创建脚本里已声明
- `human_severity_value`（面对恶人）——跨案件全局变量，专门针对赵三/王婆/投毒村民这类人类作恶者
- `fairness_value`（人妖矛盾公正度）——跨案件全局变量，目前全游戏还没案子挂过，屠窝是第一个挂载点
- `village_trust` / `weasel_trust`——**本案专属局部变量**，只用来判定这一案走结局一/二/三哪一条，不跨案件持久化
- `weasel_leader_bond`——**本案专属、但跨案件持久化**的单一 NPC 好感值，仿照紫苏（`zisu_mercy_count`）的先例，专供未来大结局"帮手名单"判断黄鼠狼首领愿不愿意出场帮忙

### 局部变量声明与结局判定

```renpy
# ---------- 故事4屠窝专属：本案信任值（本案内累加，不跨案件）----------
default village_trust = 0
default weasel_trust = 0

# ---------- 阈值常量（首次预估，待playtest调整）----------
define WEASEL_TRUST_COLLAPSE = -6   # 黄鼠狼一方彻底失望 → 结局二
define VILLAGE_TRUST_COLLAPSE = 1   # 村民对法师失去耐心 → 结局三（"低于等于"触发）

# ---------- 跨案件持久化：黄鼠狼首领对法师的具体好感，供未来大结局"帮手名单"判断 ----------
default weasel_leader_bond = 0
```

```renpy
label story4_ending_check:
    if weasel_trust <= WEASEL_TRUST_COLLAPSE:
        $ story4_ending = "ending2"
        jump ending_leader_corrupted
    elif village_trust <= VILLAGE_TRUST_COLLAPSE:
        $ story4_ending = "ending3"
        jump ending_scapegoat
    else:
        $ story4_ending = "ending1"
        jump ending_peaceful_resolution
```

判定顺序：黄鼠狼那边先判——首领彻底心死是最激烈的失控，优先级压过村民那边的动摇。

**⚠️ 待确认的设计张力**：如果玩家五个节点全部选"一视同仁/公正"一侧（节点一/二/二b/三选B，节点五选A当众揭穿），`weasel_trust`会冲到+9（远高于崩溃线），但`village_trust`会落到-1，直接触发`VILLAGE_TRUST_COLLAPSE(≤1)`——也就是说**全程对黄鼠狼最公正的玩家，反而会触发结局三（替罪羊），而不是结局一**。这可能正好呼应故事"当黄鼠狼不想打人类想打，人类想平息黄鼠狼想复仇"的错位主题（法师对妖越公正，村民越觉得他不站在自己这边，最后自己动手），但也可能不是本意。如果想让"全程秉公处理"稳定导向结局一，可以把`VILLAGE_TRUST_COLLAPSE`调低（比如-3甚至更低），或者把节点五单独摘出来不计入`village_trust`——这个取舍还没最终拍板。

### 黄鼠狼首领——未来大结局"帮手名单"判定

```renpy
define WEASEL_BOND_THRESHOLD = 3   # 首次预估，待整体数值平衡后再调

label finale_check_weasel_ally:
    if story4_ending != "ending1":
        # 结局二首领已黑化成猩红修罗/未来大妖王，结局三首领基本没和法师建立信任，
        # 这两条线不检查帮手资格
        return

    if weasel_leader_bond >= WEASEL_BOND_THRESHOLD and justice_value >= 0 and corruption_value < CORRUPTION_THRESHOLD:
        $ weasel_leader_will_help = True
    else:
        $ weasel_leader_will_help = False
```

三重门槛：
- `weasel_leader_bond >= 3`——这一案里，法师有没有让首领本人真正感受到被公正对待（本案专属，不受其他案子影响）
- `justice_value >= 0`——法师整个游戏历程里，正义值有没有至少不是净负，否则首领可能听说了法师在别处的名声而犹豫
- `corruption_value < CORRUPTION_THRESHOLD`（沿用已有的60）——法师本人还没有滑向"戮妖罗刹"那个不分善恶的黑化终局

`WEASEL_BOND_THRESHOLD = 3`和`justice_value >= 0`这两个数字都是先给的估值，等大结局那边"帮手名单"的整体设计（其他案子NPC的门槛都定下来）之后应该会再校准一轮，不建议现在写死。
