按执念类型分类,而非按种族分类

# 一、为什么要弃用种族分类

现有素材里,"妖"既可以是清白的阿狸(案3),也可以是索命的疫爪猫妖(案8);"人"既可以是纯粹的贪婪加害者(林家三少爷),也可以是被逼到绝境的普通人(张晓禾)。种族/物种从来不是斩妖世界真正的判定依据——执念的类型才是。按种族分类的反派阵营图鉴,本质上是在用"外鬼"的思路给系统分类,这与全系列唯一的判定铁律"心魔胜过外鬼"直接冲突。因此建议彻底废弃"妖/鬼/魔/人"式阵营图鉴,改用下述七类执念阵营 + 一类特殊"火种"作为反派分类的唯一依据。

|   |   |   |
|---|---|---|
||**旧分类:按种族**|**新分类:按执念类型**|
|分类依据|妖/鬼/魔/人 —— 看外壳是什么|愿/冤/推/赖/遁/求/赎 —— 看内核缺什么|
|设计问题|强化"外鬼"是问题所在的错觉,与主题相悖|直接对应"心魔胜过外鬼"命题,种族只是皮相|
|同类异构|同为"妖"的阿狸(善)与疫爪猫妖(冤)机制完全不同,却被归一类|阿狸不属于反派阵营(伪妖真人心),猫妖归入"冤执",各自匹配专属破局手法|
|玩法映射|容易滑向单纯数值对抗(打怪升级)|每类对应一套专属的"疗愈/审判"玩法,呼应"暴力是下策"基调|

# 二、七类执念阵营 + 一类特殊"火种"

每一类执念阵营对应第二份文档中"共鸣值系统"里的子类型(求/赎/推/赖),并补齐了未被那四类覆盖的三种驱动模式(愿/冤/遁),形成完整的七分类体系。"火种型"人性之恶不产生共鸣值,是点燃其余七类的引信,单独列出。

## 阵营①  愿执 —— 未竟型

|   |   |
|---|---|
|**核心驱动**|对某个具体圆满场景/团聚时刻的执著渴望,情感被冻结在"最后时刻"|
|**共鸣值子类型**|不适用(个体独立执念,非集体供养)|
|**典型技法**|在特定空间内冻结时间,循环重演执念场景(如反复准备年夜饭)|
|**代表案例**|刘婆婆(序章·打卤面)|
|**克制关键**|造梦成全——以至亲信物编织幻境完成情感闭环,前提是真诚且不被拆穿|
|**黑化倾向**|低。一般不主动伤人;若被强行打散会导致空间/剧情锁死(卡关),而非黑化为战斗单位|
|**终局站队**|背景型,通常不参战,极少跨案回归|

## 阵营②  冤执 —— 冤屈型

|   |   |
|---|---|
|**核心驱动**|死于不公,渴求真相与精准清算,拒绝伤及无辜|
|**共鸣值子类型**|常与"赎"型伴生(见案8双层结构),亦可独立存在|
|**典型技法**|精准锁定真凶,绝不无差别复仇;若遭二次欺骗(伪造圆满幻境被拆穿)会剧烈反噬|
|**代表案例**|紫苏(案1·绛珠血衣)、疫爪猫妖(案8)|
|**克制关键**|精准清算(揪出真凶明正典刑)+ 真诚沟通,严禁用幻术糊弄|
|**黑化倾向**|高危。二次伤害是黑化值飙升的最大放大器,是"受害者黑化"子机制的高发阵营|
|**终局站队**|单案善终则成为终局关键盟友(紫苏、猫妖回归助拳);失败则直接进入敌对池|

## 阵营③  推执 —— 转嫁型

|   |   |
|---|---|
|**核心驱动**|不愿独自承受负面情绪,层层甩锅给下一环,链条上无单一"恶人"|
|**共鸣值子类型**|"推"型 = Σ链条环数 ×(1−该环情绪消化比例)|
|**典型技法**|寄生于转嫁链条末端;链条断裂后倒溯因果,逆向吞噬上游各环|
|**代表案例**|抱怨鬼(案2·情绪垃圾车)|
|**克制关键**|疏导宣泄(替身法器)+ 长期心境维护(诵经/习惯重建);无法靠斩杀单点解决|
|**黑化倾向**|中。疏导失败会持续死亡式扩散,但通常维持"结构病"形态,较少单点黑化为跨案BOSS|
|**终局站队**|终局三位一体之一,作为社会性顽疾持续参战|

## 阵营④  赖执 —— 依附型

|   |   |
|---|---|
|**核心驱动**|病态共生关系中"被需要"与"被照顾"的双向渴望|
|**共鸣值子类型**|"赖"型 = 需求耦合度 × 关系持续时长|
|**典型技法**|寄生于两人关系正中央;单纯切断供给端(如一方失能)不会使其消失|
|**代表案例**|巨婴魔(案5)|
|**克制关键**|渐进式能力重建(结界考验/责任重构);严禁休克式强迫|
|**黑化倾向**|特殊。不走"变强黑化"路线,而是"转移宿主"——换一段关系复现,是唯一以"复发"而非"质变"为终态的类型|
|**终局站队**|通常不参与终局战斗,作为持续游荡的隐藏伏笔角色出现|

## 阵营⑤  遁执 —— 逃避型

|   |   |
|---|---|
|**核心驱动**|借虚幻美梦逃避现实责任与痛苦,渴望被温柔地"放过"|
|**共鸣值子类型**|介于"赖"与新增维度之间,建议单列为第五种子类型|
|**典型技法**|主动编织梦境困住当事人,梦境素材直接取自当事人的逃避性精神消费(短剧/爽文)|
|**代表案例**|梦魇兽(案7)、黄粱魇(结局新增)|
|**克制关键**|入梦斗法(先胜梦魇本体才能改写梦境)+ 晒太阳/运动等长期处方|
|**黑化倾向**|低烈度但高传播性,温水煮蛙式虚耗当事人一生;对"扎根现实、无需虚幻慰藉"的存在(山精树怪一类)天生免疫|
|**终局站队**|终局三位一体之一(黄粱魇),代表"温柔诱惑型"反派分支|

## 阵营⑥  求执 —— 信仰型

|   |   |
|---|---|
|**核心驱动**|将解决问题的希望寄托于外部超自然力量,逃避直面真实问题|
|**共鸣值子类型**|"求"型 = 供奉频次 ×(1−真实问题解决比例)|
|**典型技法**|依托庙宇/古树等信仰载体规模化汲取香火愿力,规模可达全城/全社会级|
|**代表案例**|信愿魔(案6,贯穿全季主线)|
|**克制关键**|慈悲追查溯源,而非简单诛杀信仰载体(如柳树精);法师职业本身与其构成共生关系,是全系列最难根除的类型|
|**黑化倾向**|极高。是唯一被明确设定为"游戏级主线BOSS"的类型,心魔值常年游走在红线边缘|
|**终局站队**|终局最终BOSS核心,三位一体之首|

## 阵营⑦  赎执 —— 赎罪型

|   |   |
|---|---|
|**核心驱动**|以物质供奉替代真实忏悔,试图为过去的罪孽购买心安|
|**共鸣值子类型**|"赎"型 = 供奉频次 ×(1−真实忏悔程度)|
|**典型技法**|为已铸成的伤害提供廉价仪式性补偿(烧香、供品),掩盖真正的责任|
|**代表案例**|案8·猫妖外围赎罪香客群体(与阵营②冤执核心构成双层结构)|
|**克制关键**|引导真正的忏悔行动(承担/改变);严禁交易式契约,极易被识破反而激化|
|**黑化倾向**|自身不直接黑化,但持续喂养冤执型核心走向黑化,属于"共谋型"背景阵营|
|**终局站队**|通常不独立成BOSS,而是作为其他BOSS(尤其冤执型)的"燃料阵营"存在|

## 特殊阵营  火种 —— 人性之恶(非心魔本体)

|   |   |
|---|---|
|**核心驱动**|贪婪、私欲、自保,不掺杂悲剧性执念,是纯粹的主动选择作恶|
|**共鸣值子类型**|无——他们是共鸣值的点火者,而非心魔本身|
|**典型技法**|谋杀、构陷、绑架勒索、卸责甩锅,通常是引发以上任一执念型心魔诞生的直接原因|
|**代表案例**|林家三少爷/林太太(案1)、沈明遇(案3)、赵三等(案4)|
|**克制关键**|唯一无法被"化解"的类型,只能靠揭露真相 + 交由正当程序清算|
|**黑化倾向**|不适用——他们本身即是"黑化"的人性终态,没有再堕落空间;但若清算失败,会继续滋生新的执念型心魔|
|**终局站队**|从不作为盟友,是所有案件背后隐藏的病灶起点|

# 三、体系性观察

### 3.1 阵营与共鸣值子类型的对应关系

七类执念阵营中,愿/冤/推/赖/遁/求/赎并非随意排列——求、赎、推、赖四类直接对应"共鸣值系统"文档中已定义的四种共鸣子类型,愿、冤、遁三类是本次分类新补齐的三种驱动模式,建议将共鸣值公式的适用范围正式扩展为七种子类型,使两份文档的变量体系完全对齐。

### 3.2 阵营组合是常态,不是例外

案8·猫妖已经证明"冤执"(核心复仇目标)与"赎执"(外围供养香客)可以在同一案件里组成双层结构。建议系统设计上默认支持"核心执念阵营 + 外围喂养阵营"的组合模式,而非要求每个心魔只归属单一阵营——外围阵营决定心魔的体量与形态,核心阵营决定它的复仇/诉求目标。

### 3.3 火种型是唯一的"必须清算,不可超度"的类别

七类执念阵营的解法光谱是"造梦—疏导—清算—沟通—处方"等偏疗愈手段,唯独火种型(纯人性之恶)不适用任何疗愈类解法,只能靠揭露与正当程序清算——这为系统提供了一条清晰的判断准则:凡是可被感化、可被满足、可被真正忏悔打动的,归入七大执念阵营;凡是纯粹损人利己且毫无悲剧性根源的,归入火种型,直接作为"精准清算"的清算对象,不进入疗愈流程。

### 3.4 终局三位一体的阵营构成提示

结局篇最终BOSS由信愿魔(求执)、抱怨鬼(推执)、黄粱魇(遁执)三者合流构成,恰好覆盖七大阵营中最具"社会规模化"特征的三类(均可脱离单一个体、在全社会尺度自我繁殖)。愿执、赖执两类因高度依赖单一个体/单一关系,规模上限较低,天然不适合作为季终BOSS,更适合作为单案或伏笔角色;冤执、赎执则更适合作为终局的关键"盟友/燃料"变量,而非BOSS本体——这为后续赛季设计新主线反派时,提供了一条"是否具备社会规模化潜力"的筛选标准。
