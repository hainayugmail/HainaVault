## 三、行动抉择点（非四性格问法，独立机制）

### 【抉择：如何处理紫苏的执念】（第五拍末尾）

**温和（以幻境化解）**："算了，你的执念说到底也不是要害谁——我便再麻烦一趟，帮你把这桩心事走完。" → `jump gentle_dream`，进入现有"第六拍：对峙"（第二、三次幻境）→ 高潮 → 报警/沉默结局。

**强制（正面硬拼）**："事到如今，也顾不得许多了——今日便用烈火符，把你的怨气生生压下去，送你上路。" → `jump forceful_battle`，进入下方"强制分支：血战"，与温和路线完全并列、互斥。

### 【强制分支内部：血战的两个子抉择点】（已确认展开为完整剧情，不再是一句话带过）

法师撤去幻境伪装，与显出原形的紫苏正面血战。战斗中有两个连续的子抉择点，均按"选择偏温和/克制"还是"选择偏狠辣/速战"叠加 `corruption_risk`（黑化风险值），最终按累加总量收束到两个对等结局之一：

**子抉择1——用哪张符**：

- 渡魂符（先稳住她的心智，留一线体面）→ `corruption_risk +5` → `battle_choice1_a`
- 离火符（不留余地，正面强攻）→ `corruption_risk +15` → `battle_choice1_b`

**子抉择2——最后一步怎么打**（两条支线在此汇合后统一进入）：

- 以守代攻，慢慢耗尽她的怨气 → `corruption_risk +5` → `battle_ending_dispel`
- 倾尽全力正面对轰 → `corruption_risk +20` → `battle_ending_dormant`

**结局A · `battle_ending_dispel`（紫苏被打散）**：法师以近乎"渡"的方式收束怨气，紫苏最终喊出孩子的名字后彻底消散——怨气解决了，但婉婉被囚的真相和孩子的下落从此再无人能说出口，法师"赢了这一场，却什么都没查清"。

**结局B · `battle_ending_dormant`（紫苏彻底黑化蛰伏）**：正面硬拼激化了怨气而非消灭它，紫苏凝出更黑更硬的芯子，遁入库房阴影蛰伏下来，为后续案件/续作埋下伏笔——真相同样没有揭开，反而多了一个"随时可能卷土重来"的隐患。

两个结局的共同点：都刻意不解开婉婉被囚禁的真相，与温和路线"最终查明真相、走到报警/沉默抉择"形成鲜明对照——这是"强制"路线在设计上故意留下的遗憾，作为选择暴力手段的叙事代价，不需要再额外补充。

## 四、理想主义成长契机（已确认展开，挂在第四拍林耀登门施压）

最终没有挂在真相揭晓或结局抉择点，而是挂在了更早的**第四拍：林耀登门施压**——这一拍原本法师被两个保镖压阵、只能咽下一句"我知道了"，正好是理想主义者最容易被检验的位置：明知势单力薄、随时可能被灭口，要不要还是为了心里那点"该不该"把话挑明。

**触发守卫**：`get_dominant_trait() == "idealist" and polarity_idealist == None` 才会真正演出下面的抉择，否则直接沿用默认的"我知道了"，不影响其他玩家。

**积极方向（守护者雏形）**："林先生，我知道我人微言轻，惹不起林家。可这世上的事，不是谁的拳头硬，谁就有理。婉婉是死是活，紫苏怎么没的，我既然知道了，就没法再装看不见——真出了事，我认。" → 不是鲁莽对抗，是清醒地知道自己劣势却依然不退；林耀被这份底气短暂震住，后续保镖试探、林耀离场等情节照常发生，但林耀那句"松了口气"这次是真的松了口气。 → `$ polarity_idealist = "positive"`

**消极方向（审判官雏形）**："林耀，你以为拿两个打手、几句好话就能把人命买断？婉婉的命，紫苏的命，还有那孩子——今天你不给我一个交代，谁都别想干净地走出这间屋子！" → 这份"正气"里掺进了"我偏要证明我是对的"式的执拗，没能真正震慑住林耀（对方只当他是不知天高地厚），为将来把"救人"念头异化成不容他人犹豫、退让的道德绑架埋下种子。 → `$ polarity_idealist = "negative"`

正/负两条支线最终都 `jump` 回共用的 `beat4_continue`（保镖借口试探油布包、林耀打圆场离开），具体完整台词已经写进 `story1_西京红衣怨.md` 定稿正文的"理想主义成长契机"一节。
