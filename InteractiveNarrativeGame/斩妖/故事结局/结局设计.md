### 一、结局分叉的判定机制

不需要额外设计新的数值——直接复用已有系统：

```
判定条件：
  诚意值（隐性）= 整季案件里
    "真正化解执念"的次数 × 权重
  - "符纸强打/敷衍了事"的次数 × 权重
  - "只拿酬劳不追根源"的选择次数 × 权重

  ≥ 阈值（建议60%案件诚意解决）→ 光明结局
  < 阈值                        → 黑暗结局

但更重要的是两个旗标：
  zisu_dormancy_active = TRUE → 紫苏会出现
  case04_weasel_leader_status = "saved" → 黄皮精首领会出现
  case07_plague_cat_genuine_resolved = TRUE → 猫妖会出现
  case00_willow_spirit_helped = TRUE → 柳树精会出现（需要在信愿魔案里善待村口柳树）

黑暗结局触发条件：
  诚意值 < 阈值
  OR 主角心魔值 > 70（主角本身已近黑化）
```

这样旗标系统直接决定谁出现在最终决战里——**你在整季里怎么对待这些存在，决定了他们愿不愿意在最后站出来**。
