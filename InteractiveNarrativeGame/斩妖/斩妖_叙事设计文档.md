**第一部分:斩妖系统设计**

## 一、核心哲学:心魔胜过外鬼

全系列贯穿唯一一条判定铁律:妖异/鬼怪本身很少是真正需要被斩杀的对象,真正的病灶几乎总是人心——执念、贪婪、溺爱、迷信、转嫁的情绪、逃避的欲望。从序章的刘婆婆(执念而非邪祟),到案3狐妖阿狸(妖善人恶),再到案5巨婴魔(彻底没有外鬼、纯粹心魔),系统层层递进地把"斩妖"的对象从"外部异物"移向"内部心结"。终局中信愿魔反问主角"你帮的从来只是你自己的酬劳,这跟我们有什么分别",更是把这一审判对象延伸到法师(玩家)自身,构成首尾闭环。

## 二、心魔的诞生机制:三种拓扑结构

### 1. 单向转嫁链条(案2·抱怨鬼)

六个人依次将负面情绪转嫁给下一环,链条末端(不再转嫁者)独自承受全部重量而死。心魔由"无人是恶人,但共同作恶"的结构性转嫁喂养而成。关键设计:切断链条终点后,心魔会倒溯因果、逆向吞噬上游各环,造成连环死亡——提示"掐断供给"本身有反噬风险。

### 2. 双向共生闭环(案5·巨婴魔)

两个人互相供养彼此的心理需求(母亲需要被需要,儿子需要被照顾),心魔寄生在关系正中央。断开供给端(母亲瘫痪)不会让心魔消失,因为渴望本身(被照顾的执念)仍然存在——证明系统的深层原则是:心魔源于欲望/执念本身,而非维系执念的外部条件。

### 3. 结构+执念融合双层模型(案8·猫妖,首次出现)

外围(大量赎罪香客的虚伪供奉)决定心魔的"体量",内核(唯一真正欠债之人)决定心魔的"复仇目标"。二者解耦:养料和仇恨对象是两个独立变量。心魔不进行无差别复仇,而是精准锁定核心目标——这是系统里的"精准复仇/仇恨锁定"设计原则,区别于范围伤害型的普通厉鬼。

### 附:信仰经济双公式(案6、案8)

•     信愿值 = 供奉频次 ×(1 − 真实问题解决比例)  → 对未来的盲目寄托("求")

•     赎罪值 = 供奉频次 ×(1 − 真实忏悔程度)  → 对过去的逃避("赎")

两公式结构相同、内核相反,几乎覆盖民间信仰行为背后的全部动机光谱,且预留了"既想赎罪又想求庇护"的复合型案件设计空间。

## 三、判定与流派系统

系统中反复出现"四门派并行判定"的结构,目前观察到两套具体流派命名(可能是同一套原型在不同案件中的具体化呈现,或世界观中存在多个可互相替换的流派):茅山道士/密宗上师/南洋降头师/西方驱魔师(案3),以及道士/和尚/巫师/阴阳先生(案5、案8)。核心设计原则一致:

•     每个流派拥有独立的"勘测/判定手法"(起卦、因果窥探、蛊虫检测、圣水共鸣等)

•     每个流派都明确写出了其判定手法的"天生局限/翻车风险"(误判、动摇、休克式逼迫、弄巧成拙)

•     多流派往往殊途同归:判定手法不同,但对"人心恶于妖"的核心真相形成一致印证(案3四流派全部选择放过妖、审判人)

|   |   |   |
|---|---|---|
|**流派**|**判定/切入手法**|**倾向与局限**|
|茅山道士|起卦观气运,测妖气纯净度/母子二气纠缠等|门规刚性(不滥杀无辜但斩一切邪祟);易被旧日残留煞气误导而错判|
|密宗上师/和尚|佛眼观因果链,因果视角追溯前因后果|倾向'业已转则不究过往',重因果慈悲;易被伪装眼泪动摇,或说教而不给支撑致当事人自我厌弃|
|南洋降头师/巫师|血蛊/禁忌契约测当下,结果导向|不纠结过去,只看当下有无恶念残留;手段阴邪,易激化矛盾或休克式逼迫致崩溃|
|西方驱魔师/阴阳先生|圣水共鸣 / 走阴问询追根溯源|对纯粹人心之恶有特殊感应;阴阳先生若调查不到位,可能'代言'亡者心愿弄巧成拙|

## 四、解法路径分类

系统内至少存在五类差异明显的解法,且有清晰的优先级/风险梯度:

•     ① 击杀/驱散(下策):对深执念型心魔基本无效(序章),对伪妖会造成误伤(案3);"强行打散"在序章会直接导致卡关,只能重开——机制上明确惩罚暴力手段。

•     ② 造梦(双刃剑):可用于圆满慰藉执念(序章),但前提是当事人心甘情愿且幻境不能被拆穿——一旦被戳穿(案1),会引爆比原来更剧烈的怨气反噬。同一手法也可被心魔本身用来加害(案7梦魇兽反向困住受害者),证明"入梦"是中性法术工具而非天然的善法。

•     ③ 引导宣泄+替身法器(案2):以桃木人等替代物承接当事人怨气宣泄,辅以长期诵经/生活处方作维持——这是"心理疗愈"取向的解法,强调持续性而非一次性斩断。

•     ④ 精准清算(案4):区分首恶与无辜,把真正的责任人交由受害方明正典刑处置,是目前评价最高的"善解"范式。

•     ⑤ 长期调理/生活处方(案2、案7):诵经、晒太阳、运动、走出家门等非战斗手段,作为斩妖之后的"术后康复"环节,证明系统存在战斗之外的长期养成/日常任务玩法。

## 五、结局模板系统

从案4开始稳定出现的"三结局标准模板",几乎适用于所有多分支案件:

|   |   |   |   |
|---|---|---|---|
|**结局类型**|**触发条件**|**特征**|**出现案例**|
|圆满解法|精准区分首恶与无辜 / 及时干预 / 真诚不被拆穿|心魔真正化解或消散;当事人获得成长;新平衡建立|案0、案4、案5、案8(概念)|
|警示结局|干预时机或力度失当(休克疗法/过度道德追讨)|不渲染崩溃本身,重点是警示'粗暴干预=二次伤害'|案5(休克崩溃)、案8(和尚线警示)|
|假性圆满|找替罪羊/交易式契约/表面技能习得但心理未变|表面平息,实则新怨种埋下,为未来案件伏笔|案4(献祭)、案5(转移宿主)、案8(交易式和解)|

## 六、特殊设计机制

### 1. 受害者黑化(屠龙少年终成恶龙)

案4首次提出:被害的一方若得不到及时的心理干预(即使是非人存在),同样可能彻底黑化成为比加害者更残暴的存在,并被明确设定为"会成为其他案件里的反派原型"——证明黑化结局不是终点,而是角色跨案复用/伏笔埋设机制的一部分。

### 2. 转移宿主(心魔跨形态复现)

案5明确定义巨婴魔为"会转移宿主的现代心魔原型",同一心理病灶(病态依赖)可以在不同关系形态(亲子→恋人)中重新孵化——心魔并非绑定在单一案件的单一角色上,而是一种可复现的"原型"。

### 3. 角色跨案回归与羁绊值

终局中,紫苏(案1)、黄皮精首领(案4)、柳树精(案6)、猫妖(案8)全部以NPC身份回归,是敌是友取决于主角在各自单案中的处理方式——本季所有单案选择被系统性地汇总为一套"因果羁绊值",直接决定终局战盟友数量与结局走向。

### 4. 心魔值 / 世界善恶值累计系统

结局篇明确点出"心魔值常年游走在红线边缘""世界善恶值:彻底崩溃"等结算用语,证明存在一个贯穿全季、随每次案件选择浮动的隐藏数值,最终决定光明/黑暗结局分野,以及终局反派(信愿魔)的最终体量与形态(是否"完全实体化")。

### 5. NG+ 轮回机制

黑暗结局明确解锁"重新开始,带着这次全部的记忆与因果"的提示,证明游戏支持多周目继承记忆的新周目玩法(NG+)。

**第二部分:斩妖叙事弧**

## 一、总体结构:十篇的递进脉络

序章(打卤面)→ 案1(绛珠血衣)→ 案2(情绪垃圾车)→ 案3(狐影)→ 案4(屠窝)→ 案5(巨婴魔)→ 案6(信愿魔·主线)→ 案7(美妙的梦魇)→ 案8(猫妖)→ 结局(光明/黑暗)。十篇故事并非简单并列的单元剧,而是沿着"心魔胜过外鬼"这一命题不断放大规模、加深审判尺度的一条完整弧线。

## 二、主题的三重递进

### 第一层:个体执念(序章、案1)

心魔源于单一角色未竟的情感执念(思念儿子、查明冤屈),解法聚焦在"解铃还须系铃人"式的个人心结化解,且案1已经埋下"造梦手段的风险"这条重要伏笔——它不是万灵药。

### 第二层:群体/结构性心魔(案2、案4)

心魔升级为多人共谋喂养的产物,不再有单一"恶人"(案2)或存在明确首恶但也有大量无辜者卷入(案4)。这一层引入了"精准清算"与"受害者黑化"两个关键机制,系统开始区分"结构性责任"与"个体责任"。

### 第三层:存在论级与信仰级心魔(案5、案6、案7、案8)

案5彻底移除"外鬼"这一变量,证明心魔可以完全没有妖怪实体、纯粹是人心病态本身;案6(信愿魔)将心魔规模扩大到全社会的信仰经济,并首次标注"贯穿整个游戏"作为主线;案7揭示"造梦"这一法术本身也能被心魔反向利用;案8将结构性喂养与个体执念真正融合,并第一次让"该被审判的人"与"最该被同情的人"合二为一,把审判难度推向顶点。

## 三、主角(法师)的成长弧光

序章里的主角是一个斤斤计较、几乎把每单案子当买卖做的"穷酸道士",这一底色贯穿全季(案6中法师明知客户的钱可能来路不正也照收不误,甚至内心盘算"不能让他们不迷信")。这种世俗性并非单纯负面刻画,而是系统埋下的一条隐藏拷问线——法师这个职业本身在多大程度上也是被心魔(尤其是信愿魔式的信仰经济)豢养的共谋者。终局信愿魔的诘问"你帮的从来只是你自己的酬劳,这跟我们有什么分别"直接点破这条弧线,让"心魔胜过外鬼"的审判对象最终收束到玩家扮演的主角自己身上,完成了整个系列在道德层面的自反闭环。

## 四、角色羁绊与终局回响

紫苏、黄皮精首领、柳树精、猫妖在终局的回归,并非简单的"报恩"式团圆,而是伴随着尖锐的指责与不情愿("我们不是帮你们,是为了自己""你们至少是认真的")。这种设计避免了廉价的大团圆感,让"圆满结局"建立在"主角至少认真处理过"而非"主角做对了一切"之上,与三结局模板中"假性圆满≠真圆满"的原则一脉相承。

## 五、终局三位一体反派与克制关系

信愿魔(绝望/求)、抱怨鬼(转嫁情绪)、黄粱魇(温柔的逃避诱惑,终局新增)三者合流,构成"绝望铁三角"。三者分别被不同力量克制:信愿魔被"真实的反例"稀释,抱怨鬼被"不迁怒无辜的清醒执念"斩断,黄粱魇则对"扎根现实、不需要虚幻慰藉的非人存在"(黄皮精、柳树精)完全免疫,形成清晰的克制表。猫妖(大福)的存在最为特殊——它不主动攻击,仅凭"被真正哀悼过的死亡的重量"就令三魔战栗,呼应案8笔记中"未被面对的怨念"与"已被真正面对的怨念"之间的质变差异。

## 六、悬而未决的伏笔

案1中紫苏未竟的心愿——查明婉婉之死真相、带走婉婉的孩子(地下室B2)——贯穿全季始终未被解决,并在两个结局的结算画面底部都留下同一行字:"婉婉,还在......等着新的英雄出现。"光明结局中这是主角团下一步行动的起点;黑暗结局中则成为悬念与诅咒,暗示续作或下一赛季的核心线索。

## 七、主题总结

《斩妖》全季用十篇故事反复论证同一件事:真正需要被斩杀的从来不是妖,而是人心中的贪婪、溺爱、迷信、逃避与转嫁——即便偶有妖异确实害人(如序章、部分案例),其根源也总能追溯到某个人的执念或恶意。系统通过"三结局模板""心魔值累计""角色跨案回归"等机制,让每一次单案抉择都成为塑造终局审判的因果碎片,最终把这场审判的镜子转向了玩家自己——法师是否也在用"斩妖"之名,行敷衍谋利之实?这正是"心魔胜过外鬼"这一命题最锋利的落点。
